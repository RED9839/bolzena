# 화면 글 규칙 · 용어집

2026-10-21 사용자 「UI 들 다듬고 통일해 줘, 깔끔하게, 언어들도 서술체」 → 화면 문장은 **~다 체(평서문)** 로 통일한다.
대상: 판 화면(`Runtime/Flow` · `Kit` · `Data` 의 화면 글), 전투 화면(`bolzena-unity/Assets/Bolzena/Scripts`), 서버가 화면에 내보내는 까닭 글(`Web/lib` · `Web/functions`), 웹 로딩 화면(`Tools/web_post.py`), 개인정보 처리방침(`Tools/web_static/privacy.html`).
모양 통일(머리 · 판 · 빈 상태 · 잠김)은 `Docs/톤.md` §11.

**바꾸지 않는 것** — 콘텐츠 지문에 드는 글(content-v2 카드 글 · 사도 blurb · 이벤트 지문, 엔진 `CardText` 가 짓는 카드 효과 글). 사도 · NPC 대사(hero_lines · 따옴표 대사 · 골디 · 클론 보스)는 그 말투 그대로. 지난 패치노트 판.

## 1. 말투

| 자리 | 꼴 | 보기 |
|---|---|---|
| 안내 · 설명 · 부제 · 빈 상태 · 잠김 까닭 · 알림(토스트) · 서버 까닭 | **~다 체** | 「저장한 사도가 없다 — 모험을 완주하면 저장할 수 있다」 · 「3단계를 완주하면 열린다」 · 「앞 칸(03)을 먼저 열어야 한다」 |
| 확인 창 물음 | **~할까?** | 「지금 모험을 버릴까?」 · 「이 칸을 덮어쓸까?」 |
| 단추 | 짧은 명사 · 동사 | 「저장」 · 「진입」 · 「모험 시작」 · 「닫기」 |
| 칩 · 제목 · 상태 표시 · 표 머리 | 명사형 | 「잠김」 · 「비어 있음」 · 「검증 전」 · 「기록 없음」 |
| 효과 풀이(카드 · 키워드 · 적의 수 · 패턴 한 줄) | 명사형 · 개조식 | 「다음 턴 단일 30 예고 · 실드로 받기」 |

- **합쇼체 · 해요체를 쓰지 않는다** — 「~합니다 · ~하세요 · ~입니까 · ~해요」 금지.
- 시키는 말(「~하세요」 · 「~하라」) 대신 **「~할 수 있다」** · 「~하면 ~된다」. 꼭 해야 하는 것만 「~해야 한다」.
- 받침 뒤 「입니다」 → 「이다」, 모음 뒤 → 「다」(「사도입니다」 → 「사도다」 · 「3장입니다」 → 「3장이다」).
- 끝난 일 알림은 지난 꼴 — 「저장했다」 · 「불러왔다」 · 「보냈다」. 하는 중은 「~하는 중…」(명사형, 마침 없음).
- 문장 끝 마침표는 쓰지 않는다(여러 문장이 이어지는 긴 안내 · 처리방침만 쓴다). 두 문장은 「 — 」 로 잇는다.

## 2. 길이

- 부제 · 머리 풀이는 **한 줄 · 30자 안팎**. 넘치면 뺀다 — 화면이 이미 보여 주는 것(「아래 목록에서」 · 「오른쪽 아래에서」)은 쓰지 않는다.
- 같은 화면에서 같은 말을 두 번 하지 않는다(머리 풀이와 빈 상태 글이 같은 뜻이면 하나만).
- 수치는 숫자로 바로(「3번」 · 「×1.3」) — 「세 번」 · 「1.3배로」 처럼 풀어 쓰지 않는다.

## 3. 용어집 — 같은 뜻은 같은 낱말

| 낱말 | 뜻 | 쓰지 않는 말 |
|---|---|---|
| **사도** | 고르는 캐릭터 | 캐릭터 · 영웅 |
| **교주** | 플레이어(나) · 교주 카드 | 플레이어 · 유저 |
| **모험** | 마을에서 2층 보스까지 한 번 | 판 · 런 · 게임(화면 글에서) |
| **완주** | 모험의 2층 보스를 쓰러뜨림 | 클리어(모험에서) |
| **편성** | 사도 셋을 고르는 일 · 그 화면(제목은 「편성」) | 팀 편성 · 팀 |
| **파티** | 모험 · 전투에 나선 사도 셋 | 팀 |
| **덱** | 카드 묶음 | — |
| **아티팩트** | 무기 · 방어구 · 장신구(id · 코드 이름은 equip 그대로) | 장비 |
| **단계** | 난이도 단계(성장 켬) — 「3단계」(마을 고르기 상세 판의 단계 줄에서 고른다) · 잠재력 칸의 「단계 a/b」 · 칸 잠김 「난이도 단계 n 을 완주하면 열린다」 | 레벨(단계를 뜻할 때) · 난이도 n |
| **도전 사다리** | 난이도 단계 1~9 를 완주로 하나씩 여는 것(따로 고르는 화면은 없다 — 마을 고르기 안) | 랭크 · 티어 |
| **잠재력 · 칸** | 판 밖 성장(하나뿐) · 사도 잠재력 판의 한 칸 | 노드(화면 글에서) · 레벨 · 진급(없앰) |
| **저장 칸** | 프론티어에 들고 가는 사도 저장(사도마다 여러 칸). 좁은 자리는 「칸」 | 슬롯 · 저장 데이터(목록 제목 말고) |
| **보관함** | 저장 칸 전부를 보는 화면(옛 「사도 저장함」, 10-22) | — |
| **시험 칸** | 시험 계정의 서버 저장 칸(덱 만들기) | — |
| **덱 만들기** | 시험 모드 이름 | 덱랩 |
| **프론티어** | 보스 랭킹전 | 레이드 |
| **점수** | 프론티어 한 번의 피해 합 | — |
| **랭킹** | 점수 순 목록 · 그 화면. 내 자리는 **순위**(「12위」) | — |
| **기록** | 내가 낸 도전들(「내 기록」) | 이력 |
| **검증** | 서버가 다시 돌려 점수를 확인함 — 「검증 전」 · 「검증됨」 · 「검증 안 함」 | 승인(점수에서) |
| **계정 · 로그인 · 닉네임** | 디스코드 · 구글 · 기기 코드 로그인 | 아이디 |
| **골드** | 모험 안의 돈 | 돈 · 코인 |
| **마시멜로** | 잠재력 칸을 여는 재료 — **하급 · 중급 · 상급 마시멜로**(줄여 「하급」 · 「중급」 · 「상급」). 모험 끝 보상으로만 얻는다. 글보다 그림 칩(등급색 네모 + 그림 + ×수)으로 보인다(이름은 `ProgStore.MM` 과 서버 `lib/prog.js MM` 두 곳) | 잠재력 재료 ★n · 성격 재료 · 특수 재료(10-22 없앰) · 성장석 |

**없앤 기능의 낱말 — 화면 글에 쓰지 않는다**: 교주 보드 · 크레파스(10-21) · 레벨 · 진급 · 교주 레벨 · 던전 · 소탕 · 위스프 샘 · 왕사탕 · 모카롱 · 엘리프 · 강화석 · 하트 · 교본 · 판 밖 골드(10-21 밤 — 판 밖 성장은 잠재력 하나) · 학년 · 학점 · 졸업 · 진급 보상(학점제 학년, 10-22 코드에서 지움). 「골드」 는 모험 안의 돈만, 진행 코드는 「편성 프리셋 · 완주 기록」 을 옮기는 것으로만 쓴다. 어사이드 · 에고 발현 · 추억 조각 · 뽑기는 만들지 않는다.

## 4. 자주 쓰는 꼴

| 경우 | 꼴 |
|---|---|
| 빈 상태 | 「○○이 없다 — △△하면 □□할 수 있다」 · 「기록 없음」(칸 안 짧은 자리) |
| 잠김 | 칩 「잠김」 + 까닭 「○○하면 열린다」 |
| 불러오는 중 | 「불러오는 중…」 · 「랭킹을 받는 중…」 |
| 서버에 못 닿음 | 「서버에 닿지 않는다 — 잠시 뒤 다시 할 수 있다」 |
| 로그인이 필요 | 「로그인하면 ○○할 수 있다」 |
| 준비 중(서버 없음) | 칩 「준비 중」 + 「지금은 ○○만 열린다」 |
| 확인 물음 | 「○○할까?」 + 부제 「△△은 사라진다」 |
