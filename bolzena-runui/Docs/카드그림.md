# 카드 · 사도 그림 — 임시 규칙

카드 그림이 따로 그려지기 전까지 원작 그림으로 자리를 메운다. 판 화면(`W.Card`)과 전투 화면(bolzena-unity `CardView`)이 같은 규칙을 쓴다.
코드는 `Runtime/Data/CardArt.cs` 하나다. 전투 쪽에서는 `Look.CardArt`가 `"st:<그림 키>"` · `"ic:<아이콘>"` 꼴로 넘긴다.

| 카드 | 그림 | 어디서 |
|---|---|---|
| 시작 카드(사도의 기본 카드) | 그 사도 **스탠딩** 상반신 — **늘 이것**(원작 그림으로 바꾸지 않는다 · 사용자 결정 2026-10-05). 카드 비율로 잘라 머리 가운데에 맞추고, 높이의 위쪽 5.6할을 담는다 | `RunArt/Standing/<그림 키>.png` · `_meta.json` |
| 고유 카드 · 생성 카드(신탁 · 꼬리 붙은 id 도 같은 그림) | **고른 원작 그림**(아래 「원작 그림 짝」) — 카드 그림 창 비율로 미리 자른 한 장 | `cardart.json` 의 `pics` → `RunArt/CardPic/<이름>.png` |
| 〃 어울리는 그림이 없을 때 | **카드 그림 표**에 적힌 그 사도의 원작 스킬 아이콘(내용이 맞아 고른 아이콘이 있으면 그것). 흐리게 크게 늘린 바탕 위에 가운데 선명한 아이콘(성격 색 테)을 얹는다 | `cardart.json` 의 `cards` → `RunArt/Skill/<아이콘>.png` · `_blur.png` |
| 교주 카드 · 상태 · 저주 | 지금 그대로. 종류 무늬(왕관 · 해골 · 종류 아이콘)를 쓴다 — 주인 사도가 있는 교주 카드(「id@사도」)도 그림은 교주 카드 그대로(틀 색 · 핀만 주인). 그림 찾기는 `GameData.BaseId`(주인 · 꼬리를 뗀 id) | — |
| 그림 파일이 없을 때 | SD 초상(`RunArt/Heroes`). 전투는 `Resources/Art` 의 옛 그림 | — |

사도 화면(편성 큰 카드 · 사도 목록 · 사도 상세)도 같은 스탠딩을 쓴다. 목록은 위쪽 5할(상반신), 편성 카드는 7.2할(무릎께), 상세는 전신이다.
스탠딩이 없으면 미니미 SD(스파인)로, 그것도 없으면 초상으로 대신한다.

## 원작 그림 짝 — `Tools~/cardpic_picks.json` (2026-10-05)

원작 번들(MuMu)에서 뽑은 사도 그림(`C:/projects/볼제나/assets/cardart_src/<사도키>/<갈래>__<원작 이름>.png`, git 밖)을 고유 · 생성 카드에 붙인다.
콘텐츠 쪽 초안(`bolzena-content-v2/_ref/사도카드그림.json`)은 갈래 규칙으로만 골라 카드 이름과 맞춰 보지 않았으므로 그대로 두고, **사도마다 대조 시트를 직접 보고** 고친 판을 이 표에 둔다.
**원칙: 확실하지 않은 그림은 쓰지 않는다** — 애매하면 `keep`(옛 규칙 = 스킬 아이콘).

- 대조 시트: `python "Tools~/cardpic_sheet.py" <출력 폴더> [사도 id …]` — 위에 고유 · 생성 카드(이름 · 종류 · 코스트 · 글 · 효과), 아래에 후보 그림(글자표 A, B … · 10% 눈금). 후보는 story(액자 일러스트) · btn(싸우는 SD) · cg(만화 컷) · schedule(SD 전신 액자) · aside(애장품) · present(선물) · skill(스킬 아이콘 128).
  대화창 얼굴(head) · 프로필 · 클론 · 사도 없는 스킨 방 배경 · 초상(icon)은 후보에서 뺐다.
- 고르는 결: 공격 = 싸우는/무기 든 그림, 스킬 = 돕는 · 지키는 장면, 강화 = 결의 · 변신, 이름과 딱 맞는 물건(케이크 ↔ 케이크). 한 사도 안에서 같은 그림은 한 번만. 그림에 그 사도가 분명히 보여야 한다(cg 는 다른 사도가 주인공일 때가 많다).
- 한 줄 꼴: `"file": "<폴더>/<갈래>__<이름>"` + `"c": [얼굴 x, 얼굴 y(0~10 눈금), 자를 높이 몫]` · `"icon": "<스킬 아이콘>"` · `"keep": true` — 모두 `why` 한 줄.
- 결과(565장 = 135명 고유 4장 + 생성 카드): **원작 그림 237 · 내용이 맞는 스킬 아이콘 137 · 옛 규칙 191**. 고른 뒤 구운 모습을 다시 모아 보고 얼굴이 잘리거나 주인공이 흐린 것, 고른 이가 「확신 낮음」이라 적은 것은 `keep` 으로 돌렸다.
- 굽기(`Tools~/cardpic.py` — `copy_assets.py` 가 부른다): **364×512**(판 W.Card 196×276 · 전투 CardView 1.83×2.63 창 비율 · 4의 배수라 크런치가 먹는다).
  장면 그림(story · schedule)은 얼굴이 위 3.5할에 오게 `c` 로 자르고(아래 4할은 효과 글이 덮는다), cg(2:1 만화 컷)는 세로 전체를 쓰고 가로 자리만 고른다.
  투명 그림(btn · aside · present)은 성격 색 그라데이션 + 둥근 빛 위에 통째로 얹는다. 원본(930MB)은 넣지 않는다 — 구운 237장이 40MB(빌드는 크런치). 짝 표에서 빠진 옛 그림은 복사기가 지운다(Resources 는 통째로 빌드에 들어간다).
- 가져오기(`RunUiImport`): `RunArt/CardPic` 은 스탠딩과 같이 밉맵 + 트라이리니어 + 크런치(70).
- 화면: 판 `W.Card`(`CardArt.Kind.Pic`) · 전투 `Look.CardArt` → `"pc:<이름>"` → `CardView` 가 `CardArt.Pic` 을 창에 그대로 깐다. 둘 다 `CardArt.PicOf(id)` 한 표.

## 카드 그림 표 — `Runtime/Resources/RunUI/cardart.json`

`cards`(고유 카드 → 스킬 아이콘, 아래 규칙) + `pics`(고유 · 생성 카드 → 구운 원작 그림 이름, 위 짝 표에서 — 있으면 이것이 먼저). 위 짝 표의 `icon` 은 `cards` 를 덮는다.


`python "Tools~/build_cardart.py"` 가 만든다. 콘텐츠(`bolzena-content/heroes`)와 코어 샘플(`bolzena-core/Data/Sample/heroes`)의 고유 카드 554장이 들어 있다.
콘텐츠 파일은 건드리지 않는다. 화면 쪽 표이고 이름만 적혀 있다. 그림은 git 밖에서 복사한다.

사도마다 원작 아이콘은 많아야 다섯 가지이고, 생김새는 이렇게 갈린다.

| 아이콘 | 생김새 | 먼저 가는 카드 |
|---|---|---|
| `icon_admissionskill_<키>` | 기술이 터지는 한 장면(칼끝 · 빛 · 폭발) | 공격 |
| `aside_skill_<키>_1` | 금빛 바탕에 사도나 소품(버프 느낌) | 강화 |
| `aside_skill_<키>_2` · `_3` | 사도가 나오는 장면 그림 | 스킬(남으면 공격) |
| `icon_graduateskill_<키>` | 얼굴 클로즈업(고학년 표) | 마지막에만 |

고르는 순서는 대표(signature) 카드 → 강화 → 공격 → 스킬이다. 한 사도 안에서 같은 아이콘은 한 번만 쓰고, 모자라면(어사이드 아이콘이 없는 사도) 결이 맞는 것을 다시 쓴다.
손으로 바꾸려면 json 의 그 줄만 고치면 된다. 다시 뽑으면 덮이니 손댄 줄은 스크립트의 규칙에도 옮겨 둔다.

## 그림 복사(원작 에셋 — git 에 넣지 않는다)

- 시험 프로젝트: `python "Tools~/copy_assets.py"`. `Assets/Resources/RunArt/` 는 .gitignore 에 들어 있다.
- 본 프로젝트: `python Tools/copy_run_assets.py`(runui `copy_assets.py` 를 부른다). `Assets/Resources/` 는 .gitignore 에 들어 있다.
- 스탠딩 원본은 웹판 렌더 `C:\projects\볼제나\.shots\standing-webp\<사도이름>.webp`(스파인 4.1, Idle_1, Normal 스킨 한 장 — 덧스킨 · 이벤트 소품은 입히지 않는다)다.
  2026-10-05 확인: 135명 모두 스켈레톤에 `Normal` 스킨과 `Idle_1` 이 있고, 지금 규칙(`stand.html` — 스탠딩은 Normal 만)으로 다시 그린 것과 전 렌더의 차이가 가장 큰 사도도 1.7%(쉬는 동작 프레임 차이)라 다시 뽑을 사도가 없었다. 덧스킨이 있는 32명(에르핀 Event_1 · 아일라 Transform · 이드 Eye_Open 등)도 렌더는 Normal 이다.
  투명 가장자리를 잘라 긴 변 1024 까지 줄이고 2의 거듭제곱 판의 왼쪽 위에 붙인다(크런치 압축이 먹게). `_meta.json` 에 머리 가운데 x 와 그림 너비 · 높이를 적는다.
- 가져오기 설정(`Editor/RunUiSetup.cs` `RunUiImport`): 스탠딩은 밉맵 + 트라이리니어 + 크런치 압축(품질 70)이라 목록에서 작게 보여도 지글거리지 않고 빌드도 크게 붓지 않는다. 아이콘은 밉맵을 켜고, 흐린 바탕은 끈다.

`copy_assets.py` 의 `head()` 가 자동으로 판정하고, `_meta.json` 에 `[머리 가운데 x, 너비, 높이, 머리 끝 y]` 로 적는다.
- 머리 끝: 줄마다 가장 긴 불투명 구간을 재서, 위 6할 안에서 가장 넓은 줄의 38% 가 넘는 첫 줄로 잡는다. 왕관 · 귀 · 날개 · 반짝이 같은 가는 장식은 건너뛴다.
- 가운데: 머리 끝부터 높이 22% 띠에서 넓은 줄 절반의 가운데 중앙값이다.
