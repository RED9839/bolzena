## 0. 읽는 법 — 대상 낱말 (사용자 정정 2026-10-05 · 키워드.md §0 「파티 공용 규칙」 에 맞춤)

**카드 글 표기 관례(키워드.md §0)**: 표기 없음 = 파티 전원 / 「자신의」 = 카드 주인 사도만 / 「아군의」 = 자신을 뺀 다른 사도. 이 문서의 「파티 ○○」 는 카드 글에서 **표기 없음**으로, 「자신 ○○」 · 「○○의 공격 카드」 는 **「자신의」**로, 「다른 아군 · 아군 1명」 은 **「아군의」**로 옮긴다. 수치는 카드 주인 능력치 기준(실드 = 그 사도 방어력 × 계수가 공용 실드에 쌓임 · 턴 끝에 사라짐), 사기는 합연산 +20%p, 반격은 부여한 사도 방어력 150/300%, 협공은 건 사도 공격력 100%.

- **파티** — 체력 · 실드 · 받는 피해는 셋이 한 몸이다. 그리고 **키워드 버프 · 디버프(사기 · 불굴 · 결의 · 반격 · 협공 · 잔광 · 피해 감소 · 결정화 …)도 모두 파티에 걸려 셋 모두에게 적용**된다(사기 1 → 셋 모두 피해 +20%). 이 문서에서 키워드 버프의 대상은 늘 「파티」.
- **자신** — 그 사도에게만 있는 것: 고유 상태 · 고유 자원 · 그 사도 카드에 붙는 수치(「○○의 공격 카드 피해 +50%」) · 생성 카드.
- **아군 1명(지정)** — 키워드 버프를 몰아주는 것이 **아니다**. 고유 상태 하나(챔피언 · 돌볼 아이 · 반장님 …)를 아군에게 붙여 그 아군의 **행동을 계기**로 삼을 뿐이고, 보상은 파티 버프나 자신의 자원으로 나온다.
- **적 1명 · 적 전체** — 적. 「한 번에 한 적」 은 옮기면 처음부터.
- 서포터의 개성 = **어떤 파티 버프를, 언제 · 어떤 계기로 만드나**. 탱커 = 파티 몸(실드 · 받는 피해 · 반격)을 맡는다. 딜러 = 자신의 카드 피해를 키우는 제 규칙.
- 수치는 키워드.md 감각: 피해 % = 공격력, 실드 · 치유 % = 방어력, 생성 카드는 대개 0코 · 소멸/증발, 한 사도의 고유 효과 보상은 「카드 1~2장 값」 을 넘지 않게.

| 카드가 뽑힘(감응) · 손에서 버려짐(안식) — 사도 카드 단위로 | 이드 · 타이다 · 캬롯(새싹) · 에스피(내려 보낸 카드) |
| 셔플(뽑을 더미를 섞음) | 우로스 |
| 카드가 소멸함(누구 것이든) — 이미 `exhaust` 가 있으면 개수만 | 오르 · 에슈르(마도) · 우이(기억) |
| 턴 끝에 손에 남은 사도 카드(어느 카드가 몇 턴 묵었는지 — 카드 단위 카운터) | 제이드 · 스키아 · 샤샤 |
| 이번 턴 이 사도 카드를 안 냄 · 아군 하나가 지난 턴 0장 | 유미미 · 오로라 |
| 전투 끝(판 단위 기록) | 쵸피 |
| 고학년을 씀(자기) — 다음 행동 무효 · 그 턴 비용 감소 | 리스티 · 티그(영웅) · 칸나 |
| 턴 시작 무작위 하나(수수께끼 · 타로 · 착각 대상 · 달 위상 순환) | 리온 · 앨리스 · 헤일리 · 요미 |

### 5-2. 효과 · 카드 조작
| 효과 | 쓰는 사도 |
|---|---|
| 생성 카드(0코 · 소멸/증발) 를 손 · 뽑을 더미 무작위 자리 · 맨 위에 넣기 | 다야 · 캬롯 · 퓨어샤인 · 스패럿 · 셰럼 · 로네(시장) · 아멜리아(R41) · 블랑셰 · 셀리네 · 하이디 · 시온 · 벨리타 · 에르핀 · 오르 |
| 생성 카드의 「갈래」(낼 때 조건 · 무작위로 다른 효과: 원석 진품/유리 · 전리품 · 소설 속 인물 · 발명품 · 시제품 오작동) | 다야 · 스패럿 · 셰럼 · 오르 · 아멜리아(R41) |
| 생성 카드 성장(뽑을 더미에서 지난 턴 수 · 쓴 횟수로 바뀜) | 캬롯 · 아멜리아(R41) |
| 결속 카드(겹침 수에 따른 강해진 모습 — 사도별 정의) | 클로에 |
| 생성 카드 사용 제한(만든 사도는 못 냄) | 로네(시장) |
| 카드에 붙는 값(카드 인스턴스별 카운터 · 영구 증감): 소장 가치 · 충전 · 테이크 · 벼림 · 도금 · 오이 · 진열품 | 제이드 · 캐시 · 니콜 · 바나 · 피라 · 큐이 · 마요(멋짐) |
| 카드 「두 갈래로 내기」(낼 때 고름: 빵/마법 · 속삭임/외침 · 진하게 · 과충전 · 개그 · AP 더 걸기) | 에슈르 · 가비아 · 포셔 · 라이카 · 림 · 칸타 |
| 다른 사도 카드를 대신 발동(50%, 카드는 남김) · 다른 사도 행세(그 사도의 계기를 돌림) | 아멜리아 · 스피키 |
| 손 카드를 저절로 냄(AP 없이 · 무작위 적) | 샤샤 |
| 대상을 고를 수 없음(무작위 적) | 림(혼돈) |
| AP 대신 전용 자원으로 비용 | 시스트 |
| AP 가 모자라도 냄 → 다음 턴 AP 빚(`nextAp` 확장: 빚 · 탕감) | 에르핀 |
| AP 걸기 → 결과에 따라 2배 반환/잃음 | 칸타 |
| AP 투자(2턴 뒤 되돌림, 처치로 이자) · 버프 빌려주기(2턴 뒤 회수) — 「N턴 뒤」 예약 효과 | 멜루나 · 시저 · 시온 |
| 「파티가 카드 N장 더 내면」 예약(이미 예약 계기가 있으면 장수 조건만) | 마카샤 |
| 적 다음 행동에 걸리는 함정(그 행동이 공격이면 발동, 아니면 카드 귀환) | 프리클 |
| 적 다음 행동 무효 · 다른 적을 치게 함(혼란) | 리스티 · 바롱 |
| 버린 더미 맨 아래 → 손 · 버린 더미 무작위 소멸 · 다른 아군 버린 더미에서 빌리기(턴 끝 반납) | 네티 · 스피키(메이드) · 바리에 |
| 손 ↔ 뽑을 더미 맨 위 맞바꾸기 · 뽑을 더미 위 3장 보고 1장 맨 아래로(예지) | 롤렛 · 에스피 |
| 소멸 더미 → 뽑을 더미 맨 위 · 소멸 더미 크기 비례 | 에슈르(마도) · 우이(기억) |
| 상태 카드 넣기(사도 쪽에서) · 상태 카드를 다른 카드로 바꾸기 · 파티 해로운 효과를 다음 턴으로 미루기 | 포셔 · 우이 |
| 적의 이로운 효과 · 겹 지우기(1단위) | 레테 |
| 적에게 「무작위 3종 중 하나」 를 걸고 3종 모임을 셈 | 셰이디 |
| 다음 아군 공격 한 장을 약점 공격으로 바꾸는 적 표식 | 베루 |
| 초과 피해 · 넘친 치유를 값으로 넘기기 | 아이시아 · 디아나 |
| 파티가 쓰러질 피해에서 HP 1로 버팀(전투당 1) | 벨라 |
| 열 이동 카드 + 「선 열에 따라」 갈래 | 죠안 |
| 판 단위 사도 성장(전투 넘어 남는 공격력) | 쵸피 |

### 5-3. 자원 · 고유 상태
- **사도 고유 자원(이름 · 최대치 · 턴 끝 유지)**: 눈물 · 금화 · 외상 · 구독자 · 주스 재고/매출 · 분신 · 스티커(종류 4 모음) · 배터리 · 자재 · 빠직 · 투자 · 참음 · 근력 · 당 · 봉인 · 악몽 · 초침 · 훈장(파티 공용으로 씀) · 땡땡이 · 지지율 · 나이테 · 스텝 · 맞장구 · 꿈 일기 · 혼돈 · 존속 · 열기 · 환호 · 기도 · 졸업 미룸 · 낮잠 · 나른함 · 빡침 · 노트 · 수련(판 단위) · 원고.
- **태세(상태 하나만 켜짐)**: 참는/박살 자세 · 외교관/첩보원 · 뮤트/나타 의장 · 명상 · 봉인 단계 · 달 위상(4단 순환) · 모래섬 층(무너짐 조건 포함) · 열.
- **적에게 붙는 사도 표식**: 초대장 · 무법자 · 결투 · 특종감 · 입주 · 뒷담 · 외계인(착각) · 좌표 · 깃발(적마다 1번) · 함정 · 민트 · 마취 · 폭탄 · 꿀범벅 · 서리 · 번짐 · 장난(3종) · 흠 · 시선 · 옐로/레드카드.
- **소환물(마리 수 · 따라 치기 · 대신 사라짐 · 턴 끝 행동 · 자폭)**: 목장 친구 · 에피콘 · 드론 · 벌.
- **아군에게 붙는 사도 표시(키워드 버프 아님 — 계기용)**: 챔피언 · 돌볼 아이 · 제자 · 반장님 · 물총.
