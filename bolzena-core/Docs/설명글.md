# 설명 글 원칙 (2026-10-05)

> 키워드 · 사도 고유 효과 · 패시브 · 고학년 설명을 쓰는 법. 「자세히 보기」 는 없앴다 — **처음 보이는 글 하나에 수치가 다 들어 있어야 한다.**
> 엔진 글 생성기(`Runtime/Text/CardText.cs`)와 사도 데이터(`heroes/*/*.json` 의 keyword(s) · passives · ult)가 이 원칙을 따른다.

## 1. 한 줄 = 「무엇을 하면 → 무엇이 얼마나」

- 한 줄에 계기 하나와 결과를 **숫자로** 쓴다. 계기와 결과 사이는 ` → `.
  - 예: `자신의 공격 카드를 낼 때마다 → 적 1명에게 「깃발」 +1 (턴당 1회)`
  - 예: `「깃발」이 있는 적이 쓰러지면 → 드로우 1, AP +1 (턴당 1회)`
- 계기가 없는 성질(최대치 · 1당 · 사라짐)은 계기 없이 짧게 쓴다.
  - 예: `적에게 쌓는다 · 적마다 최대 3` / `「과충전」 1당 자신의 주는 피해 +20%` / `내 턴이 끝나면 모두 사라진다`
- 한 효과는 **1~3줄**. 줄이 둘 이상이면 줄마다 앞에 `· ` 를 붙여 줄바꿈으로 나눈다. 같은 계기의 결과 여럿은 한 줄에 `,` 또는 ` · ` 로 잇는다.
- 이야기식 머리말(「먼저 찜한 쪽이 임자 —」 「시범 수업 —」)은 본문에 쓰지 않는다. 쓰고 싶으면 이름 옆 **작은 부제**로만(아래 §4).

## 2. 꼭 넣을 것

| 항목 | 쓰는 꼴 | 예 |
|---|---|---|
| 수치 | %, 횟수, 최대치 — 숫자로 | `공격력 120% 피해` · `드로우 1` · `최대 3` |
| N당 | `「이름」 1당 …`, 엔진 키워드는 `사기 1당 …` | `사기 1당 카드 피해 계수 +20%p` |
| 대상 | 아래 대상 낱말 | `적 1명에게` · `적 전체에` · `자신의` · `아군의` |
| 지속 | 이번 턴 · N턴 · 전투 끝까지 · 발동하면 사라짐 · 1 감소 | `1턴` · `턴마다 1 감소` · `쓸 때마다 1 감소` |
| 제한 | 턴당 N회 · 전투당 N회 · 카드 하나에 한 번 | `(턴당 1회)` |

- %와 %p: 카드 계수에 더하는 것(사기 · 불굴)은 **%p**, 결과에 곱하는 것(취약 · 약화 · 고유 효과의 피해 증감)은 **%**.
- 수치의 바탕: 피해 % = 카드 주인 공격력, 실드 · 치유 % = 카드 주인 방어력(따로 적으면 그것).

## 3. 대상 낱말 (이미 정한 것 — Docs/키워드.md §0)

- **표시 없음 = 파티 전체**(체력 · 실드 · 버프 · 디버프는 파티 공용). 패시브 계기에서 파티를 짚을 때는 `파티가 피해를 받으면` · `파티 HP가 30% 이하가 되면` 처럼 「파티」 를 쓴다.
- **「자신의」 = 카드 주인(그 사도)**. 패시브 계기 `play` 에 who 가 없으면 「자신의 … 카드를 낼 때마다」.
- **「아군의」 = 자신을 뺀 아군**(`다른 아군이 …`도 같은 뜻).
- 적: `적 1명`(고른 적 · 그 카드의 대상) · `적 전체` · `무작위 적` · `그 적`(앞에서 가리킨 적 — 표식이 붙은 적 · 때린 적).

## 4. 사도 고유 효과(키워드) 글의 짜임

화면에는 **이름 + 부제(작은 글) + 본문(줄 목록)** 으로 보인다. 엔진 `CardText.Traits(hero)` 가 이 묶음을 만든다.

1. **부제 = 데이터 `desc`**: 무엇인지 한 구절(12~20자 안팎). **숫자 · 조건 · 결과를 쓰지 않는다** — 그건 본문이 규칙에서 만든다. 이야기 맛은 여기에만.
   - 좋음: `공격으로 꽂는 깃발` · `제 몸에 꽂은 220V` · `제자가 공격하면 쌓이는 수업 점수`
   - 나쁨: `먼저 찜한 쪽이 임자 — 공격으로 꽂는 깃발. 꽂힌 적이 쓰러지면 AP · 드로우`(머리말 · 수치 없는 결과)
2. **본문 = 엔진이 규칙에서 만든다**(손으로 쓰지 않는다):
   - 첫 줄: 쌓는 곳 · 최대 (`적에게 쌓는다 · 적마다 최대 3` · `자신에게 쌓는다 · 최대 5` · `아군에게 붙이는 표시 · 사도마다 하나`)
   - 1당 증감 · 턴 끝 피해/회복
   - 성질(약점으로 맞음 · 대신 맞음 · 태그 · 퍼짐 · 변신)
   - 사라짐(적의 차례가 끝나면 −1 · 내 턴이 끝나면 모두 · 공격 카드에 실리면 모두)
   - 키워드 자신의 규칙(`rules` — 다 차면 터지는 효과 · 넘침 따위)까지만. **그 키워드를 쌓는 패시브는 패시브 칸에 둔다**(2026-10-06 사용자 「패시브 칸 따로」 — 모아 두었더니 112명의 패시브 칸이 사라져 「누구는 패시브가 있고 누구는 없다」로 읽혔다).
3. 패시브 칸: `passives` 전부를 이름과 함께 같은 꼴(`계기 → 결과`)로. 같은 이름 규칙 여럿은 한 칸. 패시브가 없는 사도는 「없음」 한 칸(세 칸은 늘 따로 보인다).
4. 고학년: 이름 + `게이지 N%` 부제 + 효과 글 전부.

예 — 그윈
```
고유 효과 「깃발」 (부제: 공격으로 꽂는 깃발)
· 적에게 쌓임 · 적마다 최대 3
· 「깃발」이 있는 적은 아군 카드에 약점으로 맞음 — 카드 1장이 칠 때마다 −1

패시브 「먼저 찜한 쪽이 임자」
· 자신의 공격 카드를 낼 때마다 → 그 적에게 「깃발」 +1 (턴당 1회)
· 「깃발」이 있는 적이 쓰러지면 → 드로우 1, AP +1 (턴당 1회)
```

## 5. 엔진 키워드(TIPS) 글

`CardText.TIPS` — 낱말에 밑줄을 눌렀을 때 뜨는 글. 한두 줄, 수치는 `Rules.cs`(R.STATUS_V 등) 값 그대로.
- 꼴: `누구에게 · 무엇이 얼마나 · 지속`. 예: `사기` = `파티 · 사기 1당 카드 피해 계수 +20%p(최대 10) · 전투 끝까지`
- 횟수형은 `쓸 때마다 1 감소`, 세기형은 `줄지 않는다`, 1턴은 `다음 내 턴 시작에 사라진다`.

## 6. 데이터를 쓰는 사람에게

- 규칙(when · conds · fx · limit · cap · endClear …)을 바꾸면 글은 저절로 바뀐다. **desc 에는 규칙을 옮겨 적지 않는다** — 옮겨 적으면 규칙만 바뀌고 글이 거짓말이 된다.
- 확인: `bz.cmd hero <id> --data …` 로 엔진 글을 읽어 본다. 대조 스크립트(설명글 검사)는 desc 에 숫자 · 결과 낱말이 있으면 잡는다.
- 카제나의 글을 옮기지 않는다 — 키워드 이름과 숫자로 엔진이 짓는다.

## 7. 카드 글 — 줄 나눔과 조건 문구 (2026-10-07)

> 사용자: 「찢기 · 맨주먹 한 방의 『손패가 없으면』 이 『낸 다음 손패가 0장이면』 인지 헷갈린다 · 줄 띄워 가독성」. 조사 · 개수 · 전후 예시: `bolzena-content-v2/_measure/설명글_가독성.md`.

엔진 `CardText.Card · Oracle · Bless` 가 짓는다(데이터 desc 는 그대로). `CardText.Fx` 를 바로 부르는 곳(패시브 · 장비 · 고학년 · 로그)은 한 줄 그대로.

1. **한 줄 = 한 문장**: 태그 줄(화면은 태그 칸으로 옮기고 글에서 뺀다) → 머리 줄(`비용은 「X」로` · `AP 빚 가능 — 모자란 AP만큼 다음 턴 AP -` · `갈래 — A / B`) → 기본 효과 → **조건 하나당 한 줄** → 예약 한 줄 → 강화 규칙 하나당 한 줄. 줄 머리 「· 」 는 카드 글에 쓰지 않는다.
2. **조건은 엔진이 보는 때 그대로**: 카드는 손패에서 먼저 빠진다 → `낸 뒤 손패가 없으면` · `낸 뒤 AP가 N 이상 남으면`(규칙 속은 `그 뒤`). `이번 턴 첫 카드면` · `N번째 카드면`. `이번 턴 사도 모두가 카드를 냈으면(이 카드 포함)`.
3. **같은 적은 「그 적」**: 한 카드의 두 번째부터의 `적 1명` = 카드의 대상 → `그 적`. 적 상태 조건도 `그 적이 격파 상태면` · `그 적의 강인도가 50% 이하면`(앞 효과 뒤) · 적에게 쌓는 고유 효과는 `그 적에게 「X」가 있으면`. 앞에서 짚은 적이 없으면 `고른 적`. 갈래마다 새로 센다.
4. **조건 효과는 얹힌다**: 기본 효과와 같은 갈래(피해 · 실드 · 회복)면 끝에 `더`(`그 적에게 공격력 90% 피해 더`). 조건이 둘 서면 둘 다 붙는다. 갈래 · 영감 · 안식처럼 따로 도는 때는 `더` 없음.
5. **이음**: 말로 쓴 조건 · 계기 = `조건 → 효과`, 키워드 머리 = `처치: 효과`. 강화 규칙 = `이 전투 동안 계기 → 효과 (턴당 N회)`, 규칙의 주체는 `자신의`. 예약 뒤 지금 효과는 다음 줄, 예약 안쪽 조건은 `; `.
6. **화면**: 전투 카드 글 칸은 글이 많으면 위로 0.16까지 늘어난다(CardView — 글자 1.3 아래로 안 줄게) · 판 화면 W.Card 는 6줄(96px)까지 112 칸 안.
7. **낱말 판**: 카드 글의 키워드 · 상태 · 사도 고유 효과 · **변신**(성전 모드 · 맨주먹 전성기 …)은 색 · 밑줄 + 판(runui CardTerms). 변신 판 = 부제 desc + `CardText.FormBody`(규칙에서). 판 화면 카드에 마우스를 올려 두면 카드 옆에 판을 모두(CardSide). 사도 칸(Traits)에 「변신」 칸.
