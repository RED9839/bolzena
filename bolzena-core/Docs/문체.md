# 문체 · 용어 (2026-10-05)

> 화면에 나오는 모든 한국어 글의 말투와 낱말을 하나로 맞춘다. 설명 글을 짓는 법(한 줄 = 계기 → 결과, 수치를 다 넣기)은 [설명글.md](설명글.md)에 있다. 이 문서는 **어떤 끝말로 쓰고 어떤 낱말을 쓰는지**를 정한다.
> 검사 도구: `Tools~/TextCheck/style.cmd`(§6). 위반 0을 유지한다.

## 1. 글의 갈래와 끝말

| 갈래 | 어디 | 끝말 | 예 |
|---|---|---|---|
| **효과 글** | 카드 효과 · 신탁 · 축복 · 키워드 설명(TIPS) · 사도 고유 효과 · 패시브 · 고학년 · 장비 · 교주 카드 효과 · 상태 칩 · 적의 수 · 적이 쌓는 수치 · 이벤트 결과 목록 | **명사형 · 개조식.** 명사 · 「~ㅁ/음」 · 「~기」로 끝낸다. 「~한다」 「~합니다」 「~준다」 금지 | `적 1명에게 공격력 120% 피해. 드로우 1` · `파티 · 사기 1당 카드 피해 계수 +20%p(최대 10) · 전투 끝까지` · `턴이 끝나도 손에 남음` · `적에게 쌓임 · 적마다 최대 3` |
| **안내 글** | 메뉴 설명 · 단추 아래 작은 글 · 빈 화면 · 확인 창 · 툴팁 안내 · 설정 설명 · 오류 · 알림 · 이벤트 · 마을 지문 · 카드 · 장비 · 적의 이야기 글(blurb) | **합니다체.** 확인 창의 물음은 「~할까요?」, 부탁은 「~하세요」까지 쓴다 | `누르면 바로 바뀝니다` · `낡은 상자가 놓여 있습니다` · `지금 모험을 버릴까요?` · `카드를 먼저 고르세요` |
| **이름 · 단추** | 화면 제목 · 탭 · 단추 · 카드 · 장비 · 패시브 · 적 행동 이름 · 적이 쌓는 수치의 부제 | **명사로 짧게.** 동작 단추는 「~하기」 | `모험 시작` · `도감` · `설정` · `출발` · `떠나기` · `팔기` · `뿌리 얽기` · `광석 깨짐` |
| **선택지** | 이벤트 선택지(label · leave) | **「~하기」 명사형** | `장비 사기` · `한 장만 뒤집기` · `카드 덮어 두기` |
| **대사** | 사도 대사 · 말풍선 · 혼잣말 · 적의 외침(「」 · " " · 「!」로 끝나는 말) · 지문 속 큰따옴표 | **캐릭터 말투 그대로.** 고치지 않는다 | `"정품만 취급해요, 고객님."` · `「이제 진짜 세트다!」` · `저기다!` |

- 효과 글에서 계기는 「~면」 「~할 때마다」로 이어 쓴다 — 끝이 아니라서 허용(`적이 쓰러지면 → 드로우 1`).
- 이야기 글에 명사로 끝나는 조각(`와작.` `요정들이 나눠 준 케이크.`)은 그대로 둔다. 억지로 「~입니다」를 붙이지 않는다.
- 지문의 명령(「먼저 끊어라」)은 권하는 꼴로: `먼저 끊는 편이 좋습니다`.
- 결과 목록(이벤트 결과 · 상점 기록)은 효과 글처럼 명사 조각(`골드 +50` · `「X」 — 덱에`), 문장으로 쓸 때는 합니다체(`다음 전투에서 신탁이 꼭 뜹니다`).

### 효과 글 끝말 바꾸는 법

| 쓰지 않음 | 씀 |
|---|---|
| 적에게 쌓는다 | 적에게 쌓임 |
| 모두 사라진다 | 모두 사라짐 |
| 손에 남는다 | 손에 남음 |
| 낼 수 없다 · 안 된다 | 낼 수 없음 · 불가 |
| 저절로 나간다 | 저절로 나감 |
| 변신이 풀린다 | 변신 해제 |
| 전열로 옮긴다 | 전열로 이동 |
| 힘을 모은다 — 다음 턴 … | 힘 모으기 — 다음 턴 … |
| 쓰러진 척 — … 일어선다 | 쓰러진 척 — … 일어섬 |
| N턴 뒤 체력 50%로 되살아난다 | N턴 뒤 HP 50%로 부활 |

## 2. 용어집 — 쓸 낱말 · 쓰지 않을 낱말

| 개념 | 쓸 낱말 | 쓰지 않을 낱말 | 비고 |
|---|---|---|---|
| 행동 자원 | **AP** (`AP +1` · `다음 턴 AP -1`) | 행동력 · 「AP 1」(증감에 부호 없이) | 증감은 늘 부호를 붙인다 |
| 카드 뽑기(효과) | **드로우 N** · 거르면 `자신의 공격 카드 1장 드로우` | 「1장 뽑기」 「카드 1장」만 | 더미 이름 「뽑을 더미」는 그대로 |
| 카드 값 | **비용** (`비용 0 카드` · `다음 카드 비용 -1` · `비용 1 이상 공격 카드`) | 코스트 · 「0코」 「2코」 | 신탁 머리 `비용 1.` |
| 막는 값 | **실드** · **방어** (엔진에서 따로 도는 두 값) | 보호막 · 방어막 | 「막」 같은 비유는 이야기 글에서만 |
| 생명 | **HP** (`파티 HP` · `최대 HP` · `HP가 가장 높은 적`) | 체력 | 고유 이름(「체력증진」 「기초 체력부터」)은 예외 |
| HP 채우기 | **회복** (`HP 회복(방어력 N%)` · `회복량 +N%`) | 치유 | 고유 이름 · 역할 이름(「치유의 펜던트」 「치유사」)은 예외 |
| 고른 적 | **적 1명** | 적 하나 · 대상 적 | 앞에서 가리킨 적은 **그 적**(표식이 붙은 적 · 카드의 대상), 계기가 짚으면 **친 적 · 때린 적** |
| 적 모두 | **적 전체** | 적 모두 · 모든 적(효과 글에서) | |
| 우리 편 | 표시 없음 = **파티 전체**, `자신의` = 카드 주인, `아군의` = 자신 뺀 아군 | 아군 전체 · 아군 전원 | 사도마다 따로 붙는 것: **사도마다**(전원) · **아군마다**(자신 빼고) |
| 사도 키워드 | **고유 효과** (`자신의 고유 효과 +1`) | 키워드(화면 글에서) | 카제나 키워드(사기 · 취약 …)는 이름 그대로 |
| 궁극 기술 | **고학년** (`고학년을 쓰면` · `고학년 게이지 +30%`) | 고학년 스킬 · 궁극기 · 필살기 | |
| 적의 버팀 | **강인도** · 0이 되면 **격파** | 그로기 | |
| 약점 | **약점 공격** | 약점 피해 | |
| 이로운 · 해로운 상태 | **버프 · 디버프** | 이로운 효과 · 해로운 효과 | |
| 싸움 한 번 | **전투** | 싸움 | 동사 「싸우다」(`싸울수록`)는 그대로 |
| 플레이 한 번 전체 | **모험** (`모험 시작` · `이번 모험 적 속성` · `모험이 끝날 때까지`) | 판 · 런 | 「보드게임판」 같은 말은 상관없음 |
| 플레이어 · 주인공 | **교주** (`교주 카드`) · 동료는 **사도** | 주인공 · 플레이어 | |
| 카드 종류 | **공격 · 스킬 · 강화** 셋 (그 밖에 상태 · 저주) | | |
| 횟수 제한 | **(턴당 N회)** · **(전투당 N회)** · `카드 하나에 한 번` | 한 턴에 한 번 · 1턴에 1번 | |
| 지속 | `이번 턴` · `N턴간` · `이 전투 동안`(효과 글 — 강화 카드 · 전투 끝까지 남는 증감 모두) · `전투 끝까지`(TIPS) | `전투 내내` · `이번 전투 동안`(효과 글에서) | 2026-10-07 하나로 — 한 카드에 둘이 섞여 다른 뜻으로 읽혔다 |
| 손 | 덩어리는 **손패**(`손패 2장 버리기` · `손패를 모두 버리고 섞기`), 자리는 `손에` · `손으로` · `손의 카드` | | |
| 돈 | **골드** | 돈(효과 · 화면 글에서) | 대사 · 지문의 「돈」은 그대로 |

### 수치 표기
- **%p와 %**: 카드 계수에 더하는 것(사기 · 불굴)은 `%p`, 결과에 곱하는 것(취약 · 약화 · 고유 효과의 증감)은 `%`([설명글.md](설명글.md) §2).
- 수치의 바탕: 피해 % = 카드 주인 공격력, 실드 · 회복 % = 카드 주인 방어력.
- 증감은 부호를 붙인다(`+1` · `-1` · `−1`). 쌓는 수는 `「깃발」 +1`, 상태는 `취약 2`(부호 없이 = 건다).

### 따옴표
- **「 」** = 이름 · 키워드 · 카드 · 인용(`「깃발」` · `「전술 교본」` · `「판을 엎으면 1등」`). 적의 외침도 「」로 감쌀 수 있다.
- **" "** = 지문 속 캐릭터 대사(`"…흥, 허접치고는 괜찮네."`).
- **' '**(작은따옴표)는 쓰지 않는다.
- 조사는 닫는 낫표에 붙여 쓴다(`「깃발」이 있으면`). 엔진은 `Ko.J` 로 받침을 보고 고른다.

### 이음표
- ` · ` = 같은 무게의 것 나열 · 한 줄 안의 갈래.
- ` → ` = 계기 → 결과. 카드 글의 **말로 쓴 조건**도 `낸 뒤 손패가 없으면 → …`(2026-10-07). 키워드 머리(처치 · 붕괴 · 연속 · 조율 · 영감 · 안식 · 갈래 이름)는 `처치: …` 그대로.
- ` — ` = 이름 · 머리 뒤 풀이(`재 속 — 2턴 뒤 HP 50%로 부활`).
- `. ` = 효과 글에서 다른 문장(조건 머리 「파괴:」 앞). **카드 · 신탁 · 축복 글은 문장마다 줄을 바꾼다**([설명글.md](설명글.md) §7).
- `; ` = 카드 글의 예약 안쪽 조건(`2턴 뒤 턴 시작에 → AP +2; 「수익」이 있으면 → AP +1`).

## 3. 예 — 바꾸기 전 · 뒤

| 갈래 | 전 | 뒤 |

| 효과 · 고유 효과 첫 줄 | 적에게 쌓는다 · 적마다 최대 3 | 적에게 쌓임 · 적마다 최대 3 |
| 효과 · 고유 효과 | 「깃발」이 있는 적은 아군 카드에 약점으로 맞는다 | 「깃발」이 있는 적은 아군 카드에 약점으로 맞음 |
| 효과 · 패시브 | 자신의 공격 카드를 낼 때마다 → 대상 적에게 「깃발」 +1 | 자신의 공격 카드를 낼 때마다 → 그 적에게 「깃발」 +1 |
| 효과 · 계기 | 자신의 0코 공격 카드를 낼 때마다 | 자신의 비용 0 공격 카드를 낼 때마다 |

| TIPS · 정신 붕괴 | 고학년 스킬 · 신탁을 쓸 수 없다 · … 남은 채 싸움이 끝나면 … | 고학년 · 신탁 사용 불가 · … 남은 채 전투가 끝나면 … |
| 적의 수 | 힘을 모은다 — 다음 턴 공격 300 · 격파하면 끊긴다 | 힘 모으기 — 다음 턴 공격 300 · 격파하면 끊김 |

| 이벤트 지문 | 황금빛 좌판에 진열품이 줄을 섰다. | 황금빛 좌판에 진열품이 줄을 섰습니다. |

| 단추 | 길을 떠납니다 · 그만둡니다 · 팝니다 | 출발 · 취소 · 팔기 |

## 4. 어디서 짓나

- 엔진 글(효과 글): `Runtime/Text/CardText.cs`(카드 · 신탁 · 축복 · 패시브 · 고유 효과 · 고학년 · 변신 · 적의 수 · 적 수치 · 이벤트 결과 · 장비 · TIPS), `Rules/Rules.cs`(축복 종류 · 희귀종 글).
- 엔진 안내 글: `Run/Run.cs` · `Run/RunEvents.cs`(오류 · 알림 · 이벤트 기록). 전투 로그(`Battle.Say`)는 화면에 나오지 않는 개발 기록이라 이 규칙 밖.
- 데이터: `bolzena-content-v2/world`(이벤트 · 마을 · 적 · 장비 · 교주 카드) · `heroes`(사도 이름 · 부제 desc · 고학년 이름 · 대사).
- 화면: `bolzena-runui/Runtime`(로비 · 도감 · 편성 · 지도 · 이벤트 · 상점 · 보상 · 캠프 · 설정), `bolzena-unity`(전투 UI).

## 5. 데이터를 쓰는 사람에게

- 효과는 규칙(fx · when · cond)으로 쓰고 글은 엔진이 짓는다. 데이터에 손으로 쓰는 글은 **이름 · 부제 · 이야기 · 대사**뿐이다.
- `desc`(고유 효과 부제) · `counters[].desc`(적 수치 부제)는 명사구(`공격으로 꽂는 깃발` · `턴마다 자라는 사탕수수 밭`).
- 적 행동 이름(`intents[].say` 등) · 패시브 이름은 명사(`뿌리 얽기` · `광석 깨짐`), 외침이면 느낌표로 끝낸다(`주인님인 줄 알았어!`).
- 이벤트 `scene` · 선택지 뒤 `say` 의 지문은 합니다체, 큰따옴표 대사는 그대로. 선택지 `label` · `leave` 는 「~하기」.
- 이야기 글(`blurb`)은 합니다체.
