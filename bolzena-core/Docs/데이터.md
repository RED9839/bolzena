# 볼제나 코어 — 데이터 틀

콘텐츠(사도 · 카드 · 적 · 마을 · 이벤트 · 장비)는 **JSON** 으로 손으로(또는 AI 가) 쓴다. 엔진은 글을 읽지 않는다 — 데이터가 원본이고,
카드 면 · 패시브 줄 · 적의 수 · 이벤트 결과 글은 **데이터에서 만든다**(`CardText`). 웹판의 「글 → 해석기」 를 「데이터 → 생성기」 로 뒤집었다.

파일은 몇 개든, 폴더 깊이가 어떻든 된다 — 폴더를 통째로 읽어 합친다(§10). 한 파일은 묶음 객체(필요한 키만):
```json
{ "heroes": [ … ], "cards": [ … ], "enemies": [ … ], "villages": [ … ], "events": [ … ], "equips": [ … ] }
```
콘텐츠는 `heroes/<사도키>.json`(사도 하나 + 그 카드 + 생성 카드 + 애착 장비) · `world/*.json`(그 밖) 으로 나눈다(옛 `heroes/<방식>/…` 도 읽는다 — 폴더 이름은 엔진이 안 본다). 같은 id 가 두 번이면 오류.

> **2026-10-05 키워드 사전** — 카제나 키워드를 이름 · 수치 그대로 쓴다([키워드.md](키워드.md)). 엔진과의 대응 · 층 · 고친 것은 [키워드-엔진.md](키워드-엔진.md).
> 새 콘텐츠는 **§1 · §2 「키워드 사전 조각」 · §3 · §4 · §5 · §11(사도 고유 효과 틀)** 만 보고 쓴다. 「옛」 이라 적힌 것(운영 방식 부품 · `style`)은 쓰지 않는다.
> 본보기: §12 · `Data/Sample/heroes/erpin.json`(사도) · `world/enemies.json` 의 `fairy_knight`(적) · `eq_fairycrown`(장비) · `world/cards.json` 의 `n_letter`(교주 카드).

- 읽기: `GameData.FromFolder(경로)` · `GameData.FromFolders(경로들)` 또는 `new GameData().Add(heroes, cards, enemies, villages, events, equips)`(JSON 배열 글, 없는 것은 null — 시험용, 같은 id 는 덮어쓴다).
- 키는 **camelCase**(아래 표 그대로). 모르는 키는 읽을 때 오류다(오타가 조용히 무시되지 않게).
- 검사: `Validator.Check(data)` — `Errors`(고쳐야 하는 것) · `Warnings`(docs/18 규칙에서 벗어난 것 — 효과 넷 이상, 신탁 값어치 미달 …).
- 글: `new CardText(data).Card(카드)` · `.Oracle(카드, 신탁)` · `.Bless(축복)` · `.Passives(규칙들)` · `.Keyword(키워드)` · `.Ult(고학년)` · `.Hero(사도 — 도감 한 장)` · `.Intent(수)` · `.Outcomes(결과들)` · `.Equip(장비)` · `.Enemy(적 — 쌓이는 수치 · 희귀종 · 패시브)` · `.Counter(쌓이는 수치)`.
- 칩 · 툴팁: `CardText.TIPS` · `CardText.Tip(키워드)`(엔진 키워드) · `new CardText(data).Tips()`(+ 사도 고유 효과 · 적 쌓이는 수치) · `.Chips(카드 모습)`(그 카드에 나오는 키워드 이름들).
- 스키마: `Docs/schema/*.schema.json`(JSON Schema 2020-12) — 편집기가 키 · 낱말을 자동 완성하고 틀린 키를 바로 표시한다. VS Code 는 설정의
  `"json.schemas": [{ "fileMatch": ["**/cards.json"], "url": "./Docs/schema/cards.schema.json" }, …]` 로 파일마다 잇는다. 낱말 목록은 시험(SchemaTests)이 엔진과 맞춘다.
  스키마는 꼴만 본다 — 없는 id · 키워드 · 규칙 위반은 `Validator` 가 본다.
- 샘플: `Data/Sample/` — 묶음 꼴(§10). `heroes/…/<사도>.json`(사도 + 그 카드 + 애착 장비)과 `world/*.json`(적 · 마을 · 이벤트 · 장비 · 교주/상태 카드 · 저주 · 선물). 사도 넷(**에르핀 — 키워드 사전 본보기** · 리코타 · 캬롯 · 시온은 옛 운영 방식 본보기) · 적 열하나(보스 둘, `fairy_knight` 가 적 효과 틀 본보기) · 상태 카드 다섯 · 교주 카드 여섯 · 마을 하나(에르피엔 — 요정, 세계수 숲 · 요정 왕도 두 층) · 이벤트 여섯 · 장비 아홉.
- 수치의 눈금은 웹판 v6(docs/18 §1~3) 그대로 — 사도 HP 550~1100 · 공격 60~170 · 방어 25~80, 적 체력은 데이터 값 × 층 배율.

## 1. 공통 낱말

### 대상(`target`)

| 값 | 뜻 | 글 |
|---|---|---|
| `oneEnemy` | 고른 적 하나 | 적 1명(에게) |
| `allEnemies` | 적 전체 | 적 전체(에) |
| `randomEnemy` | 무작위 적 하나(타격마다 새로) | 무작위 적 |
| `topEnemy` · `lowEnemy` | 체력이 가장 높은 · 낮은 적(고르지 않는다 — 패시브가 「다음 사냥감」 을 찍을 때 따위) | 체력이 가장 높은 적 |
| `self` | 카드 주인 | 자신 |
| `oneAlly` | 아군 한 사도(증감에만 뜻이 있다) | 아군 1명 |
| `allAllies` | 사도 셋 모두(증감 · 개인 층) | (표기 없음) |
| `otherAllies` | 자신을 뺀 사도(증감 · 개인 층) | 아군의 |
| `party` | 파티(한 몸) — 파티 층 상태 · 실드 · 회복의 기본 | (표기 없음) · 파티 |

**대상 표기(키워드.md §0)**: 표기 없음 = 파티 전원 · 「자신의」 = 카드 주인 사도만 · 「아군의」 = 자신을 뺀 사도. 증감 글: 「자신의 공격력 +10%」 · 「아군의 공격력 +10%」 · 「공격력 +10%」(파티 전원).
**수치 계산은 카드 주인의 능력치** — 피해 = 카드 주인 공격력 × (계수 + 사기 몫), 실드 = 카드 주인 방어력 × 계수(그 실드가 파티 공용 실드에 쌓인다).

파티는 **한 몸**이다(HP · 실드 · 상태가 하나). 그래서 실드 · 회복 · **이로운 · 해로운 효과(파티 층)** 는 어느 아군 대상이든 **파티에 한 번** 걸리고 파티원 전원에게 든다(사기 1 → 셋 모두 +20%p).
**개인 층**(구속 · 사도 고유 효과)과 능력치 증감(`atkMod` …)만 **가리킨 사도마다**다. 대상을 안 적으면 효과마다 기본이 있다(아래 표의 「기본」).
파티 층 상태를 `self` · `oneAlly` · `allAllies` · `otherAllies` 로 걸면 **검사기 오류**, 개인 층 상태를 `party` 로 걸어도 오류.

### 상태 이름(`status` 의 `id`)

| 갈래 | 이름 |
|---|---|
| 횟수(돌 때마다 1 준다 — 한 번의 일에 한 번) | 취약 · 약화 · 손상 · 피해 감소 · 반격 · 표식 · 잔광 · 면역 · 실드 유지 · 저장 · 협공 · 충격 · 충격파 · 그을림 · **회피**(한 대에 1) · **공명**(버린 카드 한 장에 1) · **실드 보존** · **행동 둔화** · **응징** · **미끄러움** |
| 세기(겹마다, 줄지 않는다) | 사기 · 불굴 · 결의 · 결정화 · 고동 · **칼날 벼리기** · **형상 강화** · **탄성**(발동하면 사라짐) · **포자증식**(발동하면 사라짐) · **고통 각인** · **근면** · **계몽** · **집중** |
| 1턴(다음 내 턴 시작에 사라짐) | 칼날 벼리기 · 형상 강화 · **빙벽** · **절대 무적** · **열정 약점** |
| 턴 수(내 턴 시작마다 1 준다) | **구속**(개인 층) · **초재생** · **정신 붕괴** |
| 지속(턴 끝 피해 → 절반) | 고통 · 균열 |
| 그 밖 | 잔불(적) · **다음 턴 드로우** · **죽음의 낙인**(적 — 건 카드를 기억) · **급속** · **둔화**(적 — 행동하면 사라짐) · **끈기** · 기절(적의 다음 차례를 막는다) · 리듬(옛) |
| 카드에 붙는 것(`cardStatus` · 적의 수 `cardDebuff` — `status` 로 쓰면 오류) | **독 · 봉쇄 · 침체 · 빙결 · 탐구심** · `비용`(±) · 데이터가 지은 카드 값 이름 |

값은 `R.STATUS_V` 한 표(키워드.md 수치). 층은 [키워드-엔진.md](키워드-엔진.md) 「층」 — **구속만 개인**, 나머지는 파티(적은 제 몸).
해로운 것(면역이 막고 「디버프 해제」 가 지우는 차례) = 취약 · 약화 · 손상 · 고통 · 균열 · 그을림 · 충격 · 충격파 · 잔불 · 고통 각인 · 응징 · 포자증식 · 죽음의 낙인 · 열정 약점 · 정신 붕괴 · 둔화 · 미끄러움 · 표식 · 기절.
**합연산**: 사기는 카드 계수에 겹마다 +20%p(300% → 320%), 받는 피해는 1 + 취약 0.5 - 피해 감소 0.15 - 불굴 0.2×겹 + 포자증식 0.1×겹(0 아래로는 안 간다).

### 카드 태그(`tags` — 글 맨 앞 낱말)

`개전` `보존` `소멸` `소멸 N` `증발` `종극` `주도` `유일` `연계` `천상` `신속` `분쇄` `연결` `개막` `금기` `봉인` `회수` `회수 N` `연쇄` `사용 불가`
`망각` `제거` `봉인된 금기` `약점 공격` `탄환` `결속` `축복` `열정` (+ 옛 `약점` = 약점 공격)
— 뜻은 키워드.md §2. 수가 붙는 것은 소멸(1 · 2 · 3 · 5) · 회수(3 · 4)뿐(`"소멸 2"` — 다른 수는 검사기 주의).
봉인된 금기는 카드 `becomes`, 결속은 카드 `bondCard` 가 같이 있어야 한다(§3). 열정 · 탄환은 「갈래」 태그 — 다른 카드 · 패시브(`play tag`) · 비례(`perTag` · `perPlayed`)가 센다.

## 2. 효과 조각(`fx`)

카드 · 신탁 · 축복 · 패시브 · 키워드 규칙 · 고학년 · 장비 효과가 모두 **효과 조각의 배열**을 쓴다. 조각 하나 = `{ "k": 종류, …칸 }`.
배열은 차례대로 돈다. **조건 조각**은 그 뒤의 조각들을 그 조건에 건다(글에서 「파괴: …」 처럼 새 문장이 된다).

### 피해 · 방어 · 회복

| k | 칸 | 기본 대상 | 뜻 | 글 |
|---|---|---|---|---|
| `dmg` | `ratio` · `hits` · `base:"def"` · `fixed` · `dot` · `xHits` · `xStack` | oneEnemy | 공격력 × (ratio + 사기 몫)(방어 기반: (방어력×2.1+공격력×0.3) × ratio). hits 번. 고정 피해(`fixed`)는 상태 · 상성 · 증감을 안 탄다 · 고정 지속 피해(`dot`)는 실드까지 무시 | 적 1명에게 3회 × 공격력 45% 피해 · 공격력 90% 고정 지속 피해 |
| `shield` | `ratio` · `fixed` | party | 카드 주인 방어력 × ratio 실드 — **턴이 바뀌면 사라진다**(실드 유지 · 실드 보존 예외) | 파티 방어력 150% 실드 |
| `block` | `ratio` · `fixed` | self | 옛 「방어」 — 지금은 실드와 같다(턴이 바뀌면 사라진다). 새 콘텐츠는 `shield` | 방어력 200% 방어 |
| `heal` | `ratio` | party | 방어력 × ratio 회복 | 파티 HP 회복(방어력 210%) |
| `strip` | | oneEnemy | 방어 · 실드를 0 으로 | 적 1명의 방어·실드 전부 파괴 |
| `payHp` · `payHpPct` | `v` | party | 파티 HP 를 v(비율) 만큼 치른다 | 파티 HP 90 소모 |

### 증감 — `dealtMod` · `takenMod` · `atkMod` · `defMod` · `critMod`

칸: `v`(비율 — 0.1 = +10%) · `turns`(기본 1 = 이번 턴) · `run`(전투 내내). 대상 기본: 적을 약하게 하는 것(받는 피해 + · 주는 피해 -)은 oneEnemy, 나머지는 self.
`atkMod` + `run` 은 사도마다 +150% 까지. 글: 「전투 내내 자신 공격력 +10%」 · 「2턴간 적 1명 받는 피해 +20%」.

### 자원

| k | 칸 | 뜻 · 글 |
|---|---|---|
| `draw` | `v` | 드로우 v(능력의 뽑기 — 「영감」 이 깨어난다) |
| `ap` | `v` | AP ±v |
| `nextCheaper` | `v` | 다음 카드 코스트 -v |
| `gauge` | `v` | 고학년 게이지 ±v% |
| `discard` | `v` · `all` · `random` | 손패 v장 버리기(낸 사람이 고른다 — `PlayOpts.Discard`) |
| `make` | `id`(카드 id) · `v` | 「카드」 v장 생성 — 이 전투의 손에(맨 카드: 신탁 · 축복 없음) |

### 상태 · 강인도 · 즉시 행동

| k | 칸 | 뜻 |
|---|---|---|
| `status` | `id` · `v`(겹) | 상태를 건다. 대상 기본: 해로운 것은 oneEnemy, 나머지는 party(사기는 셋 모두) |
| `cleanse` | `v` | 파티 디버프 v개 해제(해로운 것 차례대로) |

| `rushDown` | `v` | 즉시 행동 v장 늦춤 |

|---|---|---|---|
| `stack` | `id` · `v` | 사도 키워드 +v(적 표식은 고른 적에게, 아군 표식은 파티에) | 「마탄」 +1 · 적 1명에게 「수은」 +1 |

### 조건 · 비례(뒤의 조각에 걸린다)

| k | 칸 | 뜻 | 글 |
|---|---|---|---|
| `ifBroken` | | 대상이 처치됐으면(전체 · 무작위 카드는 이 카드가 하나라도 쓰러뜨렸으면) | 파괴: |
| `ifTune` | | 이 카드의 코스트가 낼 때 남은 AP 와 같으면 | 조율: |
| `ifChain` | | 이번 턴 바로 앞 카드가 같은 성격(사도)이면 | 연속: |
| `ifLink` (옛) | | 바로 앞 카드가 같은 사도의 카드면 — 서면 리듬 +1 저절로 | 잇기: |
| `ifPrev` (옛) | `type` | 바로 앞 카드의 종류가 그것이면 — 서면 리듬 +1 저절로 | 앞이 공격: |
| `ifRhythm` (옛) | `n` | 리듬이 n 이상이면 | 리듬이 3 이상이면: |
| `ifSwitched` (옛) | | 이번 턴 아군 누구든 전환했으면 | 전환: |
| `ifStack` | `id` · `n` · `max` · `not` | 키워드(고유 효과)가 있으면(n 개 이상 · max 이하이면) · 없으면 | 「X」가 있으면: · 「X」가 2~3이면: |
| `when` | `on`: draw(영감) · drawAny(감응) · discard(안식) · handEnd · burn(소각) · passion(열정) | 그 때만 도는 마디 — 카드를 낼 때는 안 돈다 | 영감: · 감응: · 안식: · 턴 끝에 손에 있으면: · 소각: · 열정: |

조건이 잇달면 **문장마다 따로** 본다 — 「파괴: AP +1. 조율: 드로우 1」 은 파괴가 서지 않아도 조율을 본다.
| `perStack` | `id` · `n`(최소) · `max`(최대) | 바로 뒤 피해 · 방어 · 실드 · 회복 한 줄을 키워드 수만큼(n · max 가 있으면 그 안으로 — 피해면 그 수만큼 친다) | 「X」 1개당 · 「X」 1개당(최소 5 · 최대 10) |
| `cue` | `id` · `v` · `xStack`(+ `n` · `max`) | 연출 쪽지 — 효과 없음, 글에 안 나옴. 쪽지 K="fx", Id = id, Hero = 주인, V = xStack 키워드의 겹(n~max 안) 또는 v. 이펙트가 그 순간에 조각을 붙인다(2026-10-06 미로) | — |
| `stack` + `ofEvent` | `ofEvent`(비율) | 일의 값(받은 · 준 피해 …) × ofEvent 만큼 쌓는다(0 이면 안 쌓음) — 값을 저장하는 고유 효과(2026-10-06 이드(재활) 「잠든 꿈」 · 키샤 「공연」). v 는 1 로 적어 둔다 | 그 값 10당 「X」 +1 |
| `dmg` · `shield` + `ofStack` | `ofStack`(고유 효과) · `ofEvent` | 그 고유 효과의 지금 겹 × ofEvent 를 고정 피해 · 고정 실드로(저장한 값을 터뜨림). ratio 는 1 로 적어 둔다 | 「X」 1당 5 고정 실드 |
| `perRhythm` | | 같은 꼴, 리듬 수만큼 | 리듬 1개당 |

예 — 「「코스」 1개당 적 1명에게 방어 기반 피해 60%, 「코스」 전부 소모. 파괴: AP +1」:

```json
  { "k": "perStack", "id": "코스" },
  { "k": "dmg", "ratio": 0.6, "base": "def", "target": "oneEnemy" },
  { "k": "spend", "id": "코스", "all": true },
  { "k": "ifBroken" },
  { "k": "ap", "v": 1 }

```

카드 쪽(효과 조각). 조건은 위 표처럼 뒤의 조각을 건다 · 비례는 바로 뒤 피해 · 방어 · 실드 · 회복 한 줄에 곱한다.

| 대가 | `burn` | `v` · `all` · `random` | 손패 v장 소멸(이 전투에서 사라진다) — 버리기처럼 낸 사람이 고른다(`PlayOpts.Discard`, `DiscardChoice` 가 센다). 「카드가 소멸하면」 을 깨운다 | 손패 1장 소멸 |

| 쌓고 고르기 · 짝 | `feed` | `v` · `target`(기본 아군 전원 · `oneAlly` · `self`) | 가리킨 사도들의 **자기 주머니 키워드**를 v 씩(키워드 이름을 몰라도 짝의 재료를 채운다 · 모드 키워드는 빼고) | 아군 전원의 키워드 +1 |

`payHp` · `payHpPct` 는 이제 치른 HP 를 세고(`perPaid`), 「HP를 치르면」 을 깨우고(카드 한 장에 한 번), 「HP가 N% 이하가 되면」 도 깨운다.

예 — 흠 세기 「적 1명의 디버프 1가지당 적 1명에게 공격력 40% 피해. 디버프가 3가지 이상이면: AP +1」:
```json
"fx": [ { "k": "perDebuff" }, { "k": "dmg", "ratio": 0.4, "target": "oneEnemy" }, { "k": "ifDebuffs", "n": 3 }, { "k": "ap", "v": 1 } ]
```
예 — 대가 「파티 HP 120 소모, 다음 턴 AP -1, 이번 턴 치른 HP 100당 적 1명에게 공격력 60% 피해」:
```json
"fx": [ { "k": "payHp", "v": 120 }, { "k": "nextAp", "v": -1 }, { "k": "perPaid" }, { "k": "dmg", "ratio": 0.6, "target": "oneEnemy" } ]
```

## 3. 카드(`cards.json`)

| 칸 | 뜻 |
|---|---|
| `id` | 고유 id(끝에 `~` · `^` 를 쓰지 않는다 — 엔진이 만든 카드 · 복제본에 쓴다) |
| `name` | 이름 |
| `hero` | 주인 사도 id. 없으면 교주 카드 · 상태 카드 · 저주 · 선물. **교주 카드**는 판에서 덱에 넣을 때 주인 사도를 고른다(덱의 id 「카드@사도」) — 그 사도의 카드로 내므로 피해(공격력) · 실드 · 회복(방어력) · 연계 · 「다른 사도 카드」 가 모두 주인 기준. 상태 카드 · 저주 · 선물은 사도 스탯을 안 쓴다(피해 · 방어 · 회복이 돌지 않는다). 카드 id 에 `@` 는 못 쓴다 |
| `cost` · `x` | 코스트 · X 코스트(남은 AP 를 전부 — `dmg.xHits`) |
| `type` | 공격 · 스킬 · 강화 · 상태 · 저주 |
| `tags` · `fx` | 태그 · 효과 |
| `unique` · `signature` | 고유 카드(은총으로 얻는다 — 아니면 시작 카드) · 시그니처 |
| `oracles` | 신탁 ①~⑤(다섯 — 아래) |
| `blesses` | 그 카드만의 축복(셋까지 — 아래). 없으면 공용 축복 풀 |
| `grade` · `price` | 교주 카드의 진열 등급(일반 · 고급 · 희귀 · 전설) · 값 |
| `gift` | 이벤트 선물 카드 |
| `blurb` | 한 줄 이야기 |
| `token` | 사도 전용 **생성 카드**(덱에 안 든다 — `make` 로만 손에) · `hero` 가 있어야 한다 · 시작 덱 · 고유 카드에 넣지 않는다 |
| `evolve` | `{ "n": 2, "into": "카드 id" }` — 같은 카드 n 장이 한 더미(손)에 모이면 into 한 장(만든 카드)으로(★ → ★★) |
| `bondCard` | 결속 — 겹친 수 3 이상일 때 이 카드(강해진 카드)의 모습으로 낸다. 결속 카드에 사도마다 정한다 |
| `becomes` | 봉인된 금기 — 보스를 처치하면 덱에서 이 카드(금기 카드)로 바뀐다 |
| `payWith` | 비용을 AP 대신 그 사도의 고유 효과(키워드, carrier self) 겹으로 치른다 — 「시간 초월로 비용 지불」 꼴 |
| `debt` | AP 가 모자라도 낸다 — 모자란 만큼 다음 턴 AP 가 준다(AP 빚) |
| `choices` | 두 갈래로 내기 — 갈래 이름 둘. 화면이 낼 때 고르고(`PlayOpts.Choice` 1 · 2) 효과는 `ifChoice` 로 가른다(§11) |

- **강화 카드** = 사도의 고유 카드이면서 `type: "강화"`. 내면 이 전투에서 사라지고(덱에는 남는다) 덱에 한 장만(유일).
- **상태 카드**(`type: "상태"`) — 적이 `addCard` 로 끼워 넣는다. 이 전투에만 있다. 「영감:」 은 턴 시작에 뽑혀도 돈다.
- **저주**(`type: "저주"`) — 이벤트의 대가로 판의 덱에 남는다.

### 신탁(`oracles` 의 한 칸)

`{ "name", "cost"(바뀐 코스트 — 없으면 그대로), "tags", "fx", "power"(「강화 카드.」 — 고르면 강화 카드가 된다) }`.
고르면 카드의 태그 · 효과를 **통째로** 갈아 끼운다(기본 카드가 유일이면 유일은 남는다). 값어치 규칙(검사기 주의): 코스트 기준 1.15배 이상 · 코스트를 올리면 1.6배 이상 · 기본에 없는 소멸은 2배 넘는 한 방에만.

### 축복(`blesses` 의 한 칸)

`{ "name", "kind", "fx", "tags" }` — `kind` 는 배율 꼴 하나(선택): `power`(피해 ×1.3) · `cost`(코스트 -1) · `weakSpot`(취약인 적에게 ×1.3) · `frost`(맞은 적 취약 1) ·
`ap`(내면 AP +1) · `draw`(내면 드로우 1) · `heal`(회복 ×1.3) · `guard`(방어 · 실드 ×1.3) · `atkUp` · `defUp`(내면 이번 전투 이 사도 +10%). `fx` · `tags` 는 카드 효과 뒤에 붙는 덤(소멸은 안 된다).
판의 `shin[카드 id]` 는 공용 꼴 이름 또는 `own` · `own1` · `own2`(그 카드의 첫째 · 둘째 · 셋째 축복).

**패시브 효과의 대상** — 패시브에는 고르는 사람이 없다. 효과의 `oneEnemy`(대상 말이 없는 적 대상 포함)는 **그 일을 당한 적**(격파 · 처치 · 디버프 · 키워드가 붙거나 사라진 · 찍힌 적이 쓰러졌으면 남은 적 가운데 첫째)이고, 그런 적이 없는 일(턴 시작 · 카드를 낼 때마다 …)이면 **살아 있는 적 가운데 첫째**다.
「카드를 낼 때마다」 는 그 카드가 고른 적이 있으면 그 적. `oneAlly` 는 그 일을 겪은 아군(카드를 낸 사도 · 맞은 자리), 없으면 패시브 주인. 적 표식 키워드의 「「X」 1개당」 · `spend` 는 그 표식을 든 적.
봇은 디버프 가짓수로 세지는 카드(`perDebuff` · `ifDebuffs`)를 가짓수가 가장 많은 적에게만 겨눈다. HP 를 치르는 카드(`payHp` · `payHpPct`)는 파티 HP 40% 밑에서 안 낸다(대가형 — 위 봇 줄).

**조건(`conds`)** — `{ "c": … }`: stack(`id` `n` `not`) · hp(`pct` 이하) · hpMin(`pct` 이상) · status(`id` `n` — 파티 · 자신 상태, 리듬도) · foes · foesMax(`n`) ·
playedMin · playedMax(`n`) · ownNone · apLeft(`n`) · gauge(`n`) · guarded(`kind`) · rushed · hurtLast · killedLast · firstTurn · targetBroken ·
**repeat**(바로 앞 두 장이 같은 카드) · **held**(`n` — 손에 n 턴 묵힌 카드가 있으면) · **spent**(`n` — 이번 턴 쓴 AP 가 꼭 n) · **balanced**(공격 · 스킬 같은 장수) ·
**debuffs**(`n` — 디버프가 n 가지 이상인 적이 있으면) · **paid**(`n` — 이번 턴 치른 HP 가 n 이상) · **wounded**(파티 체력 30% 미만 — 부상).

예 — 표적 「다음 사냥감: 찍은 적이 쓰러지면 「현상수배」 1개당 체력이 가장 높은 적에게 공격력 20% 피해, 체력이 가장 높은 적에게 「현상수배」 +2」:
```json
{ "name": "다음 사냥감", "when": { "on": "huntDown" },
  "fx": [ { "k": "perStack", "id": "현상수배" }, { "k": "dmg", "ratio": 0.2, "target": "topEnemy" }, { "k": "stack", "id": "현상수배", "v": 2, "target": "topEnemy" } ] }
```
예 — 버팀 「가시 갑옷: 공격을 방어 · 실드로 다 막으면 그 피해의 50%를 때린 적에게 고정 피해로」:
```json
{ "name": "가시 갑옷", "when": { "on": "blocked" }, "fx": [ { "k": "reflect", "ratio": 0.5 } ] }
```

봇(2026-10-04 둘째 손질 — 운영 방식을 쓴다):
- **AP 를 남기는 수** — 「턴 종료 시」 패시브 가운데 조건이 붙은 것(AP가 남았으면 · 이번 턴 자신의 카드를 안 냈으면 · 손에 묵힌 카드 …)은 조건이 지금 판에 서 있으면 그 효과의 값을 점수에 넣는다. 그래서 약한 카드를 내느니 AP 를 남기고 끝낸다.
- **「턴 끝에 손에 있으면:」** 벌점은 상태 카드 · 저주에만. 사도 카드의 그 마디는 값으로 더한다(보존 카드를 쥐고 넘긴다).
- **버릴 카드** — 상태 카드 · 저주가 먼저, 그다음 「안식:」 카드(버려지면 도는 몫 × 2 를 뺀 값이 낮은 차례).
- **쥐고 있을수록 세지는 카드**(`perStack` 뒤에 같은 키워드를 쓰지 않는 것 · `ifStack` n ≥ 2)가 손에 있으면 그 키워드 겹을 더 무겁게 쳐서 털기를 미룬다.
- **아군 1명** — 사도 셋 모두를 대상으로 둬 본다.
- HP 를 치르는 카드는 파티 HP 40% 밑에서 안 낸다. 새 조건 · 비례의 값어치는 `CardValue`(조건이 설 확률 · 보통 수)가 센다 — 판을 복사해 실제로 둬 보고 고르므로 겨누기(찍힌 적 · 디버프 많은 적)는 점수가 알아서 고른다.

**횟수(`limit`)** — `{ "per": "turn" | "fight", "n": 1 }`.
- **2026-10-09 결정(사용자 「턴당 제한 전부 없앰」)** — 사도 데이터(heroes/**: 패시브 · 키워드 규칙 · 변신 · 강화 카드 규칙 · 신탁 · 사도 파일 안 장비)의 `per: turn` 은 전부 지웠다(774곳). 새 사도 데이터에도 턴당 제한은 쓰지 않는다. 전투당(`per: fight`)은 그대로 둔다. 엔진의 `limit` 기능 자체는 남아 있다(세계 장비 · 교주 카드 · 적은 이번 결정 밖).
- **멈춤 방지 상한**(게임 규칙 아님 · 글에 안 나옴) — 같은 규칙은 한 턴에 `Battle.SAFETY_CAP`(30)번까지만 돈다(`BattlePassives.FireRule`). 기존 연쇄 상한(겹 4 · 같은 규칙 다시 들기 없음 · 예약 계기 깊이 1 · 같은 갈래 who any/other 한 사도)과 함께 계기끼리 끝없이 도는 것을 막는다. 걸린 수는 `bz sim` 끝에 찍힌다.

| `pick` | cycle(적힌 순서) · shuffle(무작위 — `w` 무게, 같은 종류 세 번 잇지 않는다). **콘텐츠 v2 는 모든 적이 shuffle**(사용자 2026-10-07 「평소 패턴은 무작위로」 — 여는 수 `open` · 판 바뀜 `phase` 는 그대로). shuffle 은 엔진이 더 거른다: 힘 모으기(`charge`)는 고른 뒤 `Battle.CHARGE_GAP`(2) 번의 고르기 동안 다시 안 고른다(모으기 → 쏟기 → 둘 → 다시 모으기가 가장 빠르다) · 소환은 `max` 가 찼거나 자리(다섯)가 없으면 안 고른다 · 회복은 다친 적(75% 아래)도 가사 상태 적도 없으면 무게 × 0.25 · 강인도를 되찾는 수(`tough` · brace)는 강인도가 반 아래면 × 2, 가득이면 × 0.5. 걸러 낸 뒤 고를 수가 없으면 거르기를 푼다 |
| `open` | 첫 턴의 수 |
| `intents` | 수 배열 |
| `phase` · `phase2` | `{ "at": 0.5, "say", "intents" }` — 체력이 그 아래로 떨어지면 수가 바뀐다(강인도가 다 찬다) |
| `rush` | 즉시 행동 장수 = **행동 카운트**(수에 없으면 이것) — 둔화 +N · 급속 -N |
| `passives` | 적 패시브(아래) |
| `counters` | **쌓이는 수치**(아래 — 분노 · 허기 · 비행 … 이름은 자유) |
| `rare` | 희귀종 덧붙임 `[{ "id", "card", "st" }]` — poisonHand(턴 시작 손 2장에 독) · reshuffle(행동할 때마다 손을 버리고 섞은 뒤 상태 카드 `card` 1장) · anxietyHits(덱의 상태 카드 `card` 수만큼 타격 +1) · autoCard(턴 시작 손의 무작위 카드가 저절로) · costUp(턴 시작 손 2장 비용 +1) · crystal(전투 시작 결정화 3) · actDebuff(행동할 때 파티에 `st` 2 — 취약 기본 · 약화) · toughGuard(받는 강인도 피해 -20%) |
| `tied` | 자기를 세운 적이 쓰러지면 같이 쓰러진다 |
| `soul` | 영혼 공유 — 영혼 공유 적 가운데 맨 왼쪽(가장 앞 Idx)이 아니면 피해 0 |
| `toughTaken` | 받는 강인도 피해 배율(0.8 = 20% 덜) |
| `toughOwn` | true 면 강인도 고정 규칙(보스 7 · 엘리트 5 · 일반 3) 대신 데이터 `tough` 를 그대로(프론티어 시즌 보스 — M.E.O.W 10). `tough` 가 있어야 한다 |

### 수(`intents` 의 한 칸)

`{ "t", "v", "n", "per", "id", "say", "w", "rush", "next", "brk", "tough", "all", "to" }`

| t | 뜻 |
|---|---|
| attack · back | 파티를 친다(back 은 관통 — 방어를 건너뛴다). `id` · `n` 이면 상태를 건다 |
| attackAll | 파티를 한 번, v × 2 |
| multi | v × n 번(방어가 먼저 벗겨진다). `id` 면 한 대마다 상태 `per`(기본 1) |
| charge | 힘을 모은다 — `next` 를 다음 턴에 반드시. `brk` 면 격파로 끊긴다(`next` 에도 `brk` 면 쏟는 턴에도). 모으는 턴에 쪽지 `foeChargeWarn`(Name 쏟을 수 이름 · Say 모으기 이름 · V 다음 턴 피해 — `b.ChargeHit(e)` · T 쏟을 수 꼴). 보스 몸에는 쓰지 않는다(보스 예고는 고학년만 — §18) |
| block · guard · heal | 자기 방어 · 적 전체 방어 · 체력 비율이 가장 낮은 적 회복 |
| buff | 자기에게(`all` 이면 적 전체) 상태 `id` +v. 세기 상태는 적 하나에 3겹까지 |
| debuff | 파티에 상태 `id` +v |
| jam | 다음 턴 AP -v |
| addCard | 상태 카드 `id` 를 n 장 — `to`: draw · discard · hand. `max` — 그 카드가 덱(뽑을 · 손 · 버린 더미)에 max 장 이상이면 무작위 고르기에서 빠진다(콘텐츠 v2 엘리트 방해 「전투당 4장 이하」, 2026-10-07) |
| summon | 적 `id` 를 n 마리 세운다(그 싸움의 체력 · 피해 배율 그대로 · 살아 있는 적이 다섯이면 못 세운다 · 세운 적의 fightStart 패시브가 돈다). `max` — 같은 적이 이만큼 살아 있으면 더 안 세운다 |
| count | 자기 쌓이는 수치 `id` 를 ±v |
| cardDebuff | 카드에 상태 `id`(독 · 봉쇄 · 침체 · 빙결)를 `to`(hand 기본 · draw) 무작위 n 장(0 = 전부). 독의 피해 = (v 또는 20) × 층 피해 배율 |
| handCost | 손 무작위 n 장(0 = 전부) 비용 ±v(그 카드를 낼 때까지 — 착란) |
| reshuffle | 손을 모두 버리고 섞는다 + 상태 카드 `id` n 장 |
| autoPlay | 손의 무작위 카드 n 장이 저절로(공짜로) 나간다 |
| shift | 지금 예고한 수를 `next` 로 바꾼다(변덕 · 변심 · 실드가 깨지면) |
| brace | 버티기 — 자기 강인도 v 회복(최대까지, 격파 중이면 안 찬다). 패시브 `do` 로도 쓴다(예: turnStart 「매 턴 강인도 1 회복」) |
| seize | 손패 흡수(2026-10-07) — 손의 무작위 카드 n 장(상태 · 저주 빼고, 손이 비었으면 뽑을 더미 맨 위 = 다음 턴에 뽑을 카드)을 그 적이 쥔다. 그 적을 **격파 · 처치**하거나 빼앗은 뒤 그 적에게 최대 HP 의 v%(없으면 `R.SEIZE_PCT` 20) 피해를 주면 모두 손으로(가득하면 버린 더미). 쥔 장수는 적 상태 칸 「빼앗은 카드」(`R.SEIZED`) · `b.SeizedOf(e)` · `b.SeizeLeft(e)`. 카드 쪽지 hand/draw → `seize` · `seize` → hand |
| revive · feign | (죽을 때 패시브만) 재 속 — n 턴 뒤 체력 v% 로 되살아난다 · 가사 — 다른 적이 heal 하면 그 값으로 일어선다 |

어느 수에나: `tough`(그 수와 함께 **자기** 강인도 되찾기 — `all` 이면 적 전체. 옛 「guard 면 적 전체」 는 없앴다) · summon 만 `noTough`(세운 소환물은 강인도 없음) · `rush`(즉시 행동 장수 — 0 은 안 당겨짐, 그 밖은 3 이상. 안 적으면 값어치로 3~6) ·
`if`(조건부 수 — `{ "allies": 3 }` 살아 있는 적이 셋 이상일 때만 · `{ "partyBlock": true }` 파티에 실드가 있을 때만(false 면 없을 때만) · `{ "selfBlock": true }` 자기에게 실드가 있을 때만 · `{ "counter": "분노", "n": 3 }` 쌓이는 수치가 n 이상일 때만. 서지 않으면 cycle 은 다음 수로, shuffle 은 후보에서 뺀다. 패시브의 `do` 에 붙으면 그 패시브가 안 돈다).
적 그림 칸 `art`: `{ "spine", "skin", "icon", "scale" }` — 엔진은 안 본다(화면 몫).
적이 거는 지속 피해(고통 · 균열 · 충격)의 바탕은 20 × 층 피해 배율.

### 적 패시브

`{ "name", "on", "at", "type", "every", "limit", "phase", "who", "same", "do" }` — `who` 는 allyDown · allyBroken 의 그 적 id(그 동료일 때만). on: fightStart · turnStart · turnEnd · hurt · lowHp(`at`) · allyDown · card(`type` — `"!공격"` 이면 공격이 아닌 카드 · `every` · `same` — 같은 사도의 카드를 잇달아 냈을 때만) ·
rushed · debuffed · broken · **allyBroken**(동료가 격파될 때 — `who` 면 그 적만, 2026-10-07) · recover · **death**(자기가 쓰러질 때 — revive · feign · 아무 수) · **guardBreak**(자기 실드가 깨질 때) · **act**(자기가 행동한 뒤) · **afterDraw**(파티가 턴 시작 손패를 뽑은 뒤 — 손에 거는 것). `do` 는 수와 같은 꼴 + `thorns`(때린 쪽에 v) · `selfHeal`. limit 기본 턴당 1(0 은 제한 없음) · phase 는 그 판에서만([0, 2]).

### 쌓이는 수치(`counters`) — 적 효과 틀

`{ "name", "desc", "start", "max", "dealt", "taken", "flat", "onHit", "onCard", "cardType", "afterAct", "onTurnStart", "resetTurnStart", "onTurnEnd", "clearTurnEnd", "at", "act", "mode", "keep", "stunAtZero" }`
겹은 그 적의 상태 칸(`Status[name]`)에 보인다. 이름은 엔진 상태와 겹치면 안 된다.

| 칸 | 뜻 |
|---|---|
| `start` · `max` | 처음 겹 · 최대(기본 99) |
| `dealt` · `taken` | 1개당 주는 피해 · 받는 피해(0.1 = +10%, 받는 피해는 합연산) |
| `flat` | 겹이 있으면 받는 피해가 이 값(과보호 1) |
| `onHit` · `onCard` · `onTurnStart` · `onTurnEnd` | 맞을 때마다 · 파티가 카드를 낼 때마다 · 턴 시작에 · 턴 끝에 ±. `cardType` 「공격」 · 「!공격」, `afterAct` — 이번 턴 이미 행동한 뒤에만 |
| `resetTurnStart` · `clearTurnEnd` | 턴 시작에 start 로 · 턴 끝에 0 으로 |
| `at` · `act` · `mode` | 겹이 at 이상이 되면 act 를 — now(즉시, 기본) · next(다음 차례의 수 — 「1턴 뒤 강공」) · replace(지금 예고한 수를 바꿈). 넘으면 start 로(keep 이면 그대로) |
| `stunAtZero` | 0 이 되면 기절(비행) |
| `clearOnAttack` | 자기가 치는 수(공격 · 관통 · 연타 · 전체)를 한 뒤 0 — 모았다가 한 방에 쏟는 꼴(「급소 노림」, 2026-10-07). 그 공격에는 실린다 |

## 6. 마을(`villages.json`)

```json
{ "id": "erpien", "name": "에르피엔", "race": "요정", "line": "파티를 고르기 전에 보이는 한 줄",
  "floors": [
    { "name": "세계수 숲", "sub": "요정 왕국 바깥 · 숲", "land": "에르피엔", "bg": { "fight": "…", "boss": "…", "event": "…" },
      "pools": [ [ [약 짝], … ], [ [중 짝], … ], [ [강 짝], … ] ],
      "elites": [ [엘리트 짝], … ], "boss": [ "보스 하나" ] },
    { 2층 … }
  ] }
```

- 마을 하나 = 종족 하나(마녀 마을은 없다). 한 판 = 마을 하나의 **두 층**(층마다 `R.FLOOR_NODES` 17 칸 — 1-1 ~ 2-17, 17번째가 보스 · 16번째가 휴식+상점). 2층 보스를 이기면 완주. 지도의 줄이 세기를 정한다(1-1~1-5 약 · 1-6~1-9 중 · 1-10~ 강 — 길 길이의 비율, 엘리트 · 휴식도 1-6 부터), 엘리트는 한 단계 센 칸에 `elites` 에서.
- **보스 칸은 보스 하나**(사용자 2026-10-06 — 졸개 없음, 둘 이상이면 검사 오류 · 엔진도 보스 줄을 보스 하나로 덜어 낸다 `Run.OneBoss`). 싸움 중 소환은 보스의 수 `summon`(`noTough`) — 그 소환물은 보스가 쓰러지면 같이 쓰러진다. 보스 칸의 사도 클론은 몸일 뿐, 판마다 그 판 적 속성으로 새로 뽑는다(§15 · 고정 보스 없음).
- 몬스터는 원작(한국 서버) 몬스터만 · 성격 갈래 없이 일반 하나(+엘리트 `_elite`) — 마을 종족 몬스터 + 종족 없는 몬스터를 섞는다. 생성기 `bolzena-content-v2/_gen/foes/build.py`, 결과 `_measure/적_리워크.md`.
- `land` 는 이벤트 풀의 이름(이벤트 `pool`). `bossElite` — 보스 데이터가 없는 층: 보스 칸이 엘리트 몸(체력 ×1.5 · 강인도 +1)으로 선다.
- 층 배율은 `R.FLOOR_HP` · `R.BOSS_HP` · `R.FLOOR_DMG`(1층 · 2층). 2026-10-09: `FLOOR_DMG` 2층 3.8 → 5.15(학년 켬 · 크레파스 없음 · 숙련 봇 역할 편성 완주 33% 맞춤 — content-v2 `_measure/갈래_세분화/06_118_진행.md` §6).

## 7. 이벤트(`events.json`)

```json
{ "id": "C3", "name": "꽃이 지지 않는 정원", "pool": "공용", "npc": "쥬비", "scene": "…", "rare": 0,
  "options": [
    { "label": "벤치에서 존다", "out": [ { "k": "hp", "v": 0.3 }, { "k": "next", "next": { "ap": -1 } } ], "say": "…" }
  ] }
```

- `pool` — `"공용"`(어느 마을 판에서든) · **마을 id**(`"erpien"` — 그 마을 판에서만, 2026-10-06 마을 이벤트) · 땅 이름(옛 꼴 — 그 층의 `land`). `floor` — 1 · 2 면 그 층에서만, 없거나 0 이면 두 층 모두.
- 뽑기: 이벤트 칸마다 마을 풀(그 마을 · 그 층) 70% · 공용 30%(`R.EVENT_FLOOR_SHARE`, 한쪽이 비면 다른 쪽), 카드 제거가 있는 이벤트는 무게 ×5. `rare` 는 굴릴 때마다 그 확률로만 후보에 든다(겨우살이 G07 = 0.5).
- **한 판에 한 번** — 이벤트가 뜨는 순간(`EnterEvent` · `PickEvent`) 「나온 것」(`EventsSeen`)에 들어가 그 판에서 다시 안 뽑힌다.
- `npc` 는 사도 이름(화면이 그 사도의 전투 스파인을 세운다) 또는 특별 이벤트의 이름(겨우살이). 없으면 배경만.
- 주의: `gamble` 이 있는 선택지는 `out` 을 쓰지 않는다(굴린 갈래의 `out` 만 적용). 값을 치르는 도박은 갈래마다 `gold` 를 넣고 `needGold` 로 잠근다.
- **조건이 안 맞는 선택지 — 잠긴 칸으로 보인다**(2026-10-07). `hero` · `race` · `when` 이 안 맞으면 선택지는 그대로 보이고 `LockOf` 가 조건 글(「루포 · 티그 가운데 한 명이 파티에 있어야 합니다」 · 「수인 사도가 파티에 있어야 합니다」 · 「파티 HP 30% 이하일 때만 고를 수 있습니다」, `lockText` 로 바꿈)을 돌려준다 — 화면은 어둡게 · 자물쇠 · 조건 글 · 누를 수 없음. `flag` · `noFlag` 조건은 기본으로 **숨긴다**(줄기 스포일러 방지). `showLocked` 로 바꾼다(true = 깃발 조건도 잠금으로 · false = 사도 조건도 숨김). 엔진 `Run.CondWhy`.
- **연속 이벤트(깃발)** — 결과 `{ "k": "flag", "id": "furry_sas_friend" }` 가 판에 깃발을 세운다(`RunState.Flags` · 판 저장에 남음 · 화면에 안 보임). 선택지 `flag`(서 있어야 보임) · `noFlag`(서 있으면 숨김), 이벤트 `needFlag`(서 있어야 뽑힘). **깃발이 서면 그 깃발을 읽는 이벤트(needFlag 충족 · 선택지 flag 깃발이 섬)의 뽑힐 무게가 ×3**(`flagWeight` 로 이벤트마다 바꿈, 기본 `R.EVENT_FLAG_WEIGHT` = 3 · 제거 ×5 와 곱함). 검사기는 세우는 이벤트보다 앞 층에서만 나오는 읽는 이벤트를 주의로 잡는다. 권장 꼴: 1층 선택지가 깃발을 세우고, 2층 이벤트의 기본 선택지 하나를 `noFlag` 로 · 그 자리를 대신할 선택지를 `flag` 로(칸 수가 늘지 않게). 검사기는 세우는 곳 없는 깃발 · 읽는 곳 없는 깃발을 주의로 잡는다. 깃발 id 는 `<마을id>_<이름>`.

선택지 칸: `label` · `out`(결과) · `say` · `hero`(사도 id 배열 — 없으면 잠긴 칸) · `race` · `when:"hp30"` · `flag` · `noFlag` · `showLocked` · `lockText` · `gamble`(`[{ "p", "out", "say" }]` — p 합 1) · `hidden`(gamble 의 확률을 화면에 안 보인다) · `choose`(gamble 을 골라서) ·
`judge`(`{ "by": "atk-max" | "hp-party", "at", "pass", "fail", "passSay" }`) · `fight`(`{ "name", "enemies", "byLand", "win", "elite" }`) · `price`(`{ "hero", "out" }`) · `needGold`.
`by`(2026-10-09 — 결과 글 say · gamble say · passSay 의 따옴표 대사마다 말하는 이, 순서대로: `null` = 장면 npc(기본) · `"hero"` = 이 선택지를 연 파티 사도(hero · price.hero 가운데 파티에 있는 사도) · 그 밖 = 이름(「경비대」 따위). gamble 항목에도 `by` 를 따로 둘 수 있다. 엔진은 `EventState.SayBy` 로 풀어 두고, 화면은 그 줄에 그 사도 이름표 · 머리 위 표시를 붙인다. 예: `"by": ["hero", null]` — 첫 대사는 동행 사도, 둘째는 npc).
「떠난다」 는 엔진이 맨 끝에 붙인다(`leave` · `leaveOut` 으로 바꾼다).

## 9. 웹판에서 뺀 것(옛 체계 잔재)

| 뺀 것 | 까닭 · 대신 |
|---|---|
| 감전 · 중독 · 침묵 · 도발 · 힘 · 가시 · 무적 | 카제나 효과 사전에 없는 옛 상태(docs/18 §5 「무적은 쓰지 않는다」). 데이터에 쓰면 검사기 오류 |
| 신탁 「trait」(날 선 손끝 · 곳간 · 성급한 손 …) | 옛 보상 신탁 — 지금은 전투 중 신탁(은총 · 카드 신탁) |
| 사도 이름에 박힌 규칙(네르 AP · 티그 오버드라이브 · 에르핀 간식 · 마요 수집품 · 아멜리아 …) · 옛 카드 실행기(applyFx) · 가시 촉수 | 기획서 이전의 손 카드 — 모든 사도는 데이터(키워드 · 패시브)로 |
| 공용 축복 「가시 돋친 꿈」(맞은 적 중독 +2) | 중독을 뺐다 |
| 효과 조각 invuln · capStack · trigger · costDelta · costSet · revive · extraTurn · lockCards · maxHpPct | 몸이 없던 것(웹판도 세기만 했다). 신탁의 코스트는 `oracles[].cost` 로 |
| 이벤트 결과의 글 읽기(「골드 -120 · 장비 (희귀)」) · 패시브 · 키워드 · 카드 글의 해석기(effects.js · passive.js parse) | 데이터 → 생성기(CardText)로 뒤집었다 |
| 사도 대사 고르기(speak) | 엔진은 난수를 쓰지 않고 `talk` 쪽지(사도 · 때)만 남긴다 — 화면이 줄을 고른다 |
| 옛 판 옮기기(migrateRun · 사도마다 HP · 우로스 · 셋째 층) | 새 판만 |

웹판과 다르게 고친 것: 횟수 상태(취약 · 약화 · 손상 · 피해 감소)는 마지막 한 겹을 첫 타격이 써도 **그 카드의 다음 타격에도 붙는다**(명세 「한 번의 일 — 여러 번 쳐도 한 번」 그대로. 웹판은 St > 0 을 먼저 봐서 빠졌다).
턴 종료 시 · 적의 차례에 얻는 AP(패시브 「AP +N」)는 다음 턴으로 넘긴다(웹판은 사라졌다). 「다음 전투: 사기 N」 은 사도 셋에게. 금기 고유 카드는 보스 복제에도 안 나온다.
즉시 행동한 적은 봇의 「받을 피해」 셈에서 뺀다(그 적은 적의 차례에 쉰다).

### 파일 꼴 — 폴더를 통째로 읽는다

데이터 경로는 **폴더** 또는 **파일**이다. 폴더면 그 아래 모든 `*.json` 을 재귀로(경로 차례) 읽어 **한 벌로 합친다**. 파일 하나는 둘 중 하나의 꼴:

- **묶음(권장)** — 객체에 필요한 키만: `{ "heroes": [ … ], "cards": [ … ] }`(키: `heroes` · `cards` · `enemies` · `villages` · `events` · `equips` · `cloneHeroes`, `$` 로 시작하는 키는 무시)

같은 id 가 두 번 나오면 **오류**(두 파일을 함께 적는다 — 사도 · 카드 · 적 · 마을 · 이벤트 · 장비 각각). 이름이 `_` 로 시작하는 파일 · 폴더(초안)와 `*.schema.json` 은 건너뛴다.
검사기 메시지에는 그 항목이 든 파일이 붙는다 — `카드 rico_u1 (heroes/pace/rico.json): …`.

콘텐츠 자리: `C:\projects\bolzena-content\`
```

world/*.json           적 · 마을 · 이벤트 · 장비 · 교주 카드 · 상태 카드 · 저주 …
```

## 11. 사도 고유 효과 틀 — 135명이 JSON 만으로 자기 규칙을

사도마다 **자기만의 고유 효과 하나**(필요하면 더 — `keywords`)를 갖는다. 카제나의 캐릭터 고유 효과 꼴(쌓는 자원 · 생성 카드 · 태세 · 적 표식 · 소환물)을 본떠
**원작 트릭컬 성격에서 새로** 짓는다(카제나 이름 · 글을 베끼지 않는다). 엔진은 이름을 모른다 — 아래 부품의 조합만 본다.

### 11-1. 고유 효과 = `keyword`(+ `keywords`)

| 칸 | 쓰는 데 |
|---|---|
| `name` · `desc` | 이름(135명 사이에서 **겹치면 오류**, 엔진 키워드 이름과 같아도 오류) · 툴팁 첫 문장(`text.Tips()[이름]`) |
| `carrier` | `self`(그 사도의 자원 · 상태 — 개인 층) · `enemy`(적에게 붙는 사도 표식) · `hero`(아군에게 붙이는 사도 표시 — 지정 아군 · 제자) · `ally`(파티에 하나) |
| `cap` · `mode` · `wrap` · `stages` | 최대 · 켜고 끄는 모드(0/1) · 순환(cap 을 넘으면 1 부터 — 단계 · 위상) · 단계 이름(글에 숫자 대신) |
| `decay` · `decayAll` · `endDecay` · `endClear` · `consume` · `consumeAll` · `wipe` · `reserve` · `hunt` | 줄어드는 법 — 적의 차례 뒤 · 내 턴 끝 · 발동하면 · 다른 사도 카드에 · 예약 · 한 적에게만 |
| `per` | 1개당 주는 피해 · 받는 피해 · 공격력 · 방어력 · 치명 · 주는 실드(`guard`) · 턴 끝 피해(`dot`) · 회복(`hot`) |
| `guard` · `weakens` | 소환물(적의 공격 한 대를 대신 받고 1 사라짐) · 적 표식(걸린 적은 아군 카드가 약점 공격) |
| `rules` | 문턱 · 사라짐 규칙 — `stackReach`(N 이 되면) · `stackGone`(사라지면 · 다 닳으면) + 아래 계기 · 효과 |

검사기: 고유 효과가 없는 사도 · 어디에도 안 쓰이는 고유 효과 → 주의. `payWith` 는 그 사도의 self 고유 효과여야 한다.

### 11-2. 계기(패시브 · 규칙 `when.on`) — §4 표 + 이것

## 13. 콘텐츠 작성자 주의

1. **상태 대상**: 이로운 · 해로운 효과는 파티 층 — `target` 을 안 적는다(적에게 거는 해로운 것은 `oneEnemy` 등). 「자신에게 사기」 · 「아군 1명에게 불굴」 은 없다(검사기 오류). 개인 층은 구속 · 고유 효과뿐.
2. **사기 · 불굴은 합연산**: 사기 2 는 100% 카드를 140% 로, 300% 카드를 340% 로 — 높은 계수 카드에서 상대적으로 덜 오른다.
3. **실드는 턴마다 사라진다** — 오래 쌓는 수비는 실드 유지 · 실드 보존 · 결정화로. 옛 `block` 대신 `shield`.
4. **강인도**: 카드 한 장이 적 하나에 약점 공격은 비용 1당 1, 아니면 1/3(여러 번 쳐도 한 번) — 강인도 3 짜리 적은 약점 1코 세 장, 아니면 아홉 장. 공명 사도는 늘 약점. 판마다 적 속성이 하나라(§15) 그 약점 성격 사도를 데려가면 격파가 잦다. `tough` 덤은 그 카드의 격파 개성일 때만(§15).
5. **반격 · 협공은 건 사도의 능력치** — 탱커가 거는 반격이 세다. 협공은 건 사도가 친다.
6. **고유 효과 이름** — 135명 사이 한 번만, 엔진 키워드(상태 · 태그)와 다른 이름. 고유 효과가 카드 · 패시브 · 고학년 어디에도 안 쓰이면 주의.
7. **카드 글은 엔진이 짓는다** — 카제나 카드 글을 옮기지 않는다. `bz hero 사도키` 로 글을 보고 뜻대로 읽히는지 본다.
8. **옛 부품 쓰지 않기** — 리듬 · 전환(`flip`) · 재촉/예약(`hasten` · `reserve`) · 잇기 · 앞이 … · 되풀이 · `style`. 남아 있지만 새 체계와 섞으면 봇 · 밸런스가 엇나간다.
9. **도발은 없다** — 끌어오기는 소환물(`guard`) · 피해 감소 · 반격으로. 키워드가 아닌 수(파티 피해 -20%)는 증감 조각(`dealtMod` …).
10. **범용으로 못 푸는 것**은 [키워드-엔진.md](키워드-엔진.md) 끝 표 — 그 사도는 표의 대안으로.

## 15. 강인도 기준(2026-10-05 — 사용자 확정 단위)

**단위** — 강인도 1 = 약점 공격 카드 비용 1. `R.ToughDmg`:

| 카드 | 약점 공격 | 약점 아님 | 근거 |
|---|---|---|---|
| 비용 1 · 2 · 3 | 1 · 2 · 3 | 1/3 · 2/3 · 1 | 사용자 확정: 비용 1당 1, 아니면 그 1/3 |
| 비용 0 | 1 | 1/3 | 0코는 비용 1 로 친다 — 비용은 최소 1(2026-10-08 사용자, 옛 1/2). 신탁 · 축복으로 0 이 된 카드 · X 로 0 낸 것도 같다 |
| X | 낸 AP × 1 | 낸 AP × 1/3 | 비용 = 낸 AP |
| 광역(allEnemies · 퍼짐) | 적마다 위와 같은 양 | 적마다 같은 양 | 2026-10-08 사용자 제보(「1코 광역이 1칸을 못 깎는다」) — 옛 「대상마다 절반」. 배율은 `R.TOUGH.Area`(지금 1) |
| 고학년 | 2 | 2/3 | 비용 2 로 친다 |
| 표식 추가 공격 | 1 | 1/3 | 비용 0 공격 = 비용 1 |
| 잔광 | +1 | +1 | 약점 1코 한 장만큼 |
| 효과 `tough v` | v | v | 약점과 상관없이 |

**약점** — 적 속성을 이기는 성격(`R.WeakTo`) · **공명 사도는 늘** · 「약점 공격」 태그 · 열정 약점 · 적 표식(weakens). 판의 적 속성(`RunState.EnemyNature`)이 있으면 모든 적(일반 · 엘리트 · 클론 아닌 보스 · 소환)이 그 성격이고 약점도 그 하나 — **사도 클론(`clone`)만 그 사도의 성격 그대로**.

**판 하나 = 적 속성 하나** — 판을 열 때 마을과 함께 속성 하나를 정하고(`Run.RollNature(d, village, r)`), 1층 · 2층 보스 줄의 사도 클론 자리를 **그 마을 종족에서 원래 성격이 그 속성인 사도**(엘다인 20명 제외 — 원작에 클론이 없다, 나무위키 엘다인 문서 · `Run.NO_CLONE`: 아야 · 시온 더 다크불릿 · 에피카 · 비비 · 클로에 · 이드 · 우이 · 우이(기억) · 리뉴아 · 실비아 · 비비(신성) · 에르핀(왕도) · 란 · 디아나(왕년) · 벨라 · 죠안 · 우로스 · 티그(영웅) · 네르(빡침) · 요미. 사도 id 그대로 빼고 바탕 이름으로 묶지 않는다 — 네르 · 디아나 · 티그 · 에르핀 · 이드(재활) · 슈로는 남는다)의 클론으로 고른다. 다른 종족에서 빌리지 않는다(사용자 2026-10-06 최종) — **1층은 1~2성, 2층은 3성 사도**(`star`, `Run.StarFits`). **그 종족에 그 속성 1~2성 사도가 없으면 1 · 2층 모두 같은 종족 3성 클론(두 층은 다른 사도)**(사용자 2026-10-06 — 옛 「그 층만 다른 성급」 대체, `Run.FloorCandidates`)(`Run.PickBosses` → `RunState.Bosses`). 이렇게 두 층을 못 채우면 그 속성은 그 마을에서 안 뽑는다(`Run.NaturesFor` · 검사기 주의) — 지금 콘텐츠는 유령 순수(3성 0) · 정령 광기(3성 0) · 용족 활발(1~2성 0 · 3성 루드 하나)이 닫힌다. 저장된 판이 닫힌 속성이면 불러올 때 씨앗으로 다시 뽑고 보스 줄도 새로 고른다(`Run.Load`). 옛 저장(보스 줄 없음)도 고정 보스 대신 그 판 씨앗 · 속성으로 새로 고른다. 보스 클론 고학년의 층은 전투가 받은 층(`BattleSetup.Floor`)을 쓴다 — 3성이 1층에 서면 1층 값. 원래 클론이 그 성격이면 그대로, 아니면 클론 데이터가 있는 사도 먼저, 없으면 그 자리 원래 클론의 몸(체력 · 수 · 강인도)을 빌린 클론(`clone~사도~몸`). 같은 사도(「티그」 · 「티그_영웅」)는 한 판에 한 번. 클론 자리를 못 채우는 속성은 그 마을에서 안 뽑는다(`Run.NaturesFor`). `bz natures` 에서 「*1~2성 없어 3성」 이 1층 3성 칸 표는 `bz natures`.
예전에 「스테이지마다 속성이 다르다」 로 보였던 까닭: 층 · 칸마다 굴리던 곳은 없었다 — 적마다 데이터 성격이 달랐고(일반 · 엘리트 · 클론 보스 모두 제각각), 판의 적 속성이 생긴 뒤에도 클론 보스만 제 성격이라 보스 싸움만 달랐다. 이제 보스를 속성에 맞춰 골라 판 전체가 한 성격.

**강인도 최소치 — 일반 3 · 엘리트 5 · 보스 7**(사용자 2026-10-06) — 모든 적의 최대 강인도는 3 이상(잔챙이 포함), 엘리트 싸움에는 5 이상 몬스터가 하나 서고, 보스는 7 이상. 예외는 하나: 수 `summon` 에 `"noTough": true` 를 적으면 그 수로 선 소환물은 강인도가 없다(최대 0 — 격파되지 않고 화면은 막대를 숨긴다). 같은 적이라도 그냥 서면 강인도가 있다. 지금 콘텐츠는 보스의 소환 수(다야 · 캬롯 · 에르핀 · 베니 · 셰이디 · 칸나 · 엘레나 · 이프리트 · 실라 몸)에만 붙였다. 이 소환물은 보스가 쓰러지면 같이 쓰러진다.

## 16. 변신(`forms`) — 2026-10-05 여섯째

고학년(또는 카드 · 패시브)의 효과 `{ "k": "form", "id": "변신 id" }` 로 **그 사도가 변신 상태**가 된다 — 모습(스파인)이 바뀌고 그동안 그 사도의 능력치 · 카드 · 패시브가 달라진다. **개인 층**(그 사도에게만, 사기 같은 파티 층이 아니다). `{ "k": "formEnd" }` 는 지금 변신을 푼다.

```json
"forms": [{
  "id": "네르_빡침_성전", "name": "성전 모드", "desc": "한 줄 설명",
  "turns": 3,                                   // 내 턴 N 번(든 턴 포함 — N+1 번째 내 턴 시작에 풀린다). 0 = 전투 끝까지
  "until": { "on": "stackGone", "id": "빡침" },  // 이 일이 나면 풀린다(패시브 when 꼴 — play · hurt · stackGone … · every N)
  "mods": { "atk": 0.1 },                       // 그동안 그 사도 능력치 — dealt · taken · atk · def · crit · guard · heal
  "cards": { "네르_빡침_s1": "네르_빡침_f1" },   // 카드 바꾸기 — 그 사도 카드 → 변신판(token 카드)
  "bonus": [{ "type": "공격", "ratio": 1.2 }, { "card": "디아나_왕년_u1", "fx": [{ "k": "formEnd" }] }],  // 카드 덤
  "passives": [{ "name": "분노 폭주", "when": { "on": "hurt" }, "fx": [{ "k": "stack", "id": "빡침", "v": 1 }] }],
  "replace": false,                             // true 면 그동안 사도 자신의 passives 가 쉰다(고유 효과 규칙 · 장비는 그대로)
  "off": [{ "k": "stack", "id": "목도", "v": 2 }],  // 풀릴 때(전투가 끝나 풀리는 것은 안 돈다)
  "skin": "?", "anim": "?"                      // 모습 키 — 스파인 스킨 · 애니 접두어(화면이 읽는다, 엔진은 안 본다)
}]
```

- **카드 바꾸기** — 손 · 더미의 카드 id 는 그대로 두고, 전투가 그 카드를 변신판으로 본다(`b.CardOf(id)` 가 변신판 모습 — 글 · 코스트 · 효과 · 태그). 풀리면 그대로 돌아온다. 고른 신탁 번호는 변신판에 그 번호의 신탁이 있으면 잇고, 없으면 변신판 기본. 변신판 카드는 `token: true`(덱 · 보상에 안 든다) · 같은 사도.
- **카드 덤** — 거르개(`card` 그 카드 · `type` · `unique` · `tag`, 모두 맞아야)에 맞는 그 사도 카드에 `ratio`(피해 · 추가 공격 배율 ×) · `fx`(덧붙임 — **첫 조건 앞에 끼워** 조건 없이 돈다) · `tags`(덧붙임).
- **같은 변신을 변신 중에 다시 쓰면 지속을 처음으로**(겹치지 않는다) — 원작의 변신(빡침 · 꿈결 형상 · 백수공권)은 다시 쓰면 시간이 새로 도는 꼴이고, 겹치면 능력치 · 카드 덤이 곱으로 불어나 값어치를 셀 수 없다. 쪽지 `formOn` 이 다시 오고 `formOff` 는 없다. **다른 변신**이면 앞의 것을 풀고(`off` 가 돈다, 까닭 `switch`) 새로.
- **검사기** — id 는 사도 사이에서 겹치면 오류 · 이름이 고유 효과 · 상태 · 태그와 같으면 오류(칩 설명이 겹친다) · `mods` 능력치 · 비율 · 변신판 카드(이 사도 · token) · 덤 · 패시브(`always` 는 안 됨 → `mods`) · 남의 변신을 부르면 오류 · 부르는 곳이 없으면 주의.
  **값어치**: 변신판 카드는 바꾸는 카드의 코스트 기준 **1.15배 이상 · 1.8배 이하**(신탁 규칙과 같은 체). 변신을 든 고학년은 `CardValue.FormValue`(지속 T 턴 — 전투 끝까지면 4 — 동안 능력치 + 바뀐 카드 차이 × 뽑힐 확률 0.45 + 덤 + 패시브 반 + 풀릴 때)를 더해 **다른 고학년 가운데값의 1.15배 이상 · 상위 10% 의 1.15배 이하**(벗어나면 주의).
- 글: `text.Form(f)`(= `Detail`) · `text.Short(f)` · 고학년 글에 「「X」로 변신(2턴)」 · `text.Hero` 에 변신 줄 · 변신판 카드 줄 · `Tips()` 에 변신 이름 · `Chips` 에 변신 이름.

- **고학년이 아닌 계기 — 고유 효과가 최대에 닿으면 변신**: 고유 효과(keyword) 정의에 `"onMax": { "form": "변신 id", "consume": false }`. 겹이 cap 에 **닿는 순간**(그 아래 → cap) 그 사도가 변신한다. `consume: true` 면 닿은 겹을 다 쓰고(「X」가 사라지면 계기도 돈다), 기본 false 면 겹은 남는다(변신의 `off` 에서 `spend all` 로 치우는 꼴 — 라이카). carrier self · cap 있는 쌓이는 고유 효과만(mode · wrap 아님, 검사기 오류). **이미 그 변신 중이면 아무 일 없다** — 고학년은 다시 쓰면 갱신이지만, 꽉 찬 자원은 변신 중에도 다시 차오르니 갱신하면 변신이 끝나지 않는다. 근거: 사용자 결정 「라이카 — 과충전이 최대로 쌓이면 최대 출력」 + 원작 「최대 출력!」 의 「해제 불가 · 일정 시간」.
- `anim` 은 변신 중 대기 동작 이름(또는 애니 접두어) — 라이카는 스킨이 그대로이고 대기만 `Idle_Change`(공격 등은 본 동작). `skin` 이 없으면 `b.FormSkin` 은 null(스킨은 기본) — 변신 여부는 `b.InForm`.

지금 든 사도(콘텐츠 v2): 죠안 「꿈결 형상」 · 네르(빡침) 「성전 모드」 · 디아나(왕년) 「맨주먹 전성기」(고학년) · 라이카 「최대 출력」(과충전 최대). 앞의 셋의 모습 키(`skin` · `anim`)는 아직 "?"(원작 스파인에서 찾는 중).

## 17. 강화 카드 지속 규칙(`power`) — 2026-10-05 일곱째

**강화 카드** = 한 번 내면 이 전투에서 빠지는 대신 **이 전투 동안 남는 효과**를 준다. 카드는 둘로 나눈다:
**낼 때 바로 받는 작은 효과(선택)** + **전투 동안 남는 효과(필수)**. 남는 효과는 셋 가운데 하나(검사기가 없으면 주의):

1. 효과 조각 `power` — 카드를 내면 그 규칙(패시브 규칙과 같은 꼴 — §4 「패시브 규칙」)이 **이 전투 끝까지** 카드 주인의 패시브처럼 켜져 있다.
2. 세기형 버프 — 사기 · 불굴 · 결의 · 결정화 · 고동 · 근면 · 계몽 · 집중(파티 층, 줄지 않는다). 강화 카드 글에서는 「이 전투 동안 결의 1」 로 읽힌다.
3. `atkMod` · `defMod` · `critMod` … + `run`(전투 내내 증감).

```json
{ "k": "power", "id": "외로운 수문장", "rules": [
    { "when": { "on": "turnStart" }, "fx": [ { "k": "stack", "id": "물총", "v": 1, "target": "allAllies" } ] },
    { "when": { "on": "play", "type": "공격" }, "limit": { "per": "turn", "n": 2 }, "fx": [ { "k": "extra", "ratio": 0.3 } ] } ] }
```
→ 「이 전투 동안 매 턴 시작 시 아군 전원에게 「물총」 +1 · 공격 카드를 낼 때마다 적 1명에게 추가 공격 30% (턴당 2회)」

| 칸 | 뜻 |
|---|---|
| `id` | 강화 이름(겹치기 · 칩의 열쇠). 없으면 카드 이름 |
| `rules` | 규칙 배열 — `when`(계기) · `conds` · `limit` · `fx` 가 패시브와 똑같다. `when.on` 은 §4 · §11-2 의 계기 아무거나(턴 시작 · 카드를 낼 때마다 · 적을 치면 · 피해를 받으면 …) |

- **켜지는 때** — 카드를 낸 그 순간부터. 그래서 `fightStart` 는 쓸 수 없다(검사기 오류). 「매 턴 시작 시」 는 다음 내 턴부터 돈다.
- **누구의 규칙** — 카드 주인 사도의 패시브와 같다(`who` 가 없으면 그 사도의 카드 · 그 사도의 일). 효과의 대상 · 계산도 패시브와 같다(§4 「패시브 효과의 대상」).
- **`always`** — 「항상」 규칙은 증감(`atkMod` · `defMod` · `critMod` · `dealtMod` · `takenMod`)만(다른 조각은 검사기 오류). 대상 `allAllies` · `party` 면 파티 전원, `otherAllies` 면 주인 빼고, 없으면 주인만. 글: 「이 전투 동안 공격력 +10%」.
- **겹치기(정함)** — 같은 사도가 같은 id 의 강화를 또 켜면(복제 · 생성 카드 · 다시 손에 온 카드) **겹 +1**. 규칙은 처음 켠 것 그대로이고, 발동할 때 **효과가 겹 수만큼 돈다**(「매 턴 시작 시 결의 1」 이 2겹이면 결의 2). **횟수 제한(`limit`)은 발동 수로 센다** — 「턴당 1회」 는 2겹이어도 한 번 발동(효과 두 번). `always` 의 증감은 겹 수만큼 곱한다. 칩은 하나(겹 숫자).
  고른 까닭: 「규칙이 하나 더 켜짐」 은 칩이 둘 생기고 횟수 제한도 둘이 되어 같은 카드 두 장이 「턴당 1회」 를 두 번 돈다 — 카드 글로 셀 수 없다. 「효과가 겹만큼」 이면 글(한 겹)과 칩(겹 숫자)만 보고 셀 수 있다.
- **어디에 쓰나** — 강화 카드(`type: "강화"`)의 `fx` 와 그 카드의 신탁, 그리고 「강화 카드.」 신탁(`power: true`). 그 밖(스킬 · 공격 · 축복 · 패시브 · 고학년 · 장비)에 쓰면 검사기 오류. 규칙 안에 power 를 또 넣을 수 없다.
- **글** — 카드 면에 「이 전투 동안 매 턴 시작 시 …」 처럼 **수치가 바로 보이는 문장**으로(`CardText.PowerText`). 턴 시작 · 턴 종료는 「매 턴 …」. 앞의 조건(「처치:」 …)에 걸리게 쓴 power 는 「처치: 이 전투 동안 …」.
- **값어치(봇 · 검사)** — 규칙마다 (한 번 발동 값 × 남은 전투 3턴 동안 발동할 수 × 0.6). 계기마다 턴당 빈도를 어림한다(`CardValue.RuleFires` — 턴 시작 1 · 자신의 카드 1.4 · 공격 카드 0.8 · 처치 0.35 …, 조건이 붙으면 × 0.6, 횟수 제한으로 자른다). 봇 점수는 켜진 강화의 남은 몫을 센다.
- **기준(콘텐츠 v2)** — 1코: 세기형 버프 1 + 사도 고유 효과를 매 턴 +1 하는 규칙 꼴이 기본. 신탁은 남는 효과를 키우는 쪽(규칙 수치 · 새 계기 하나 더 · 낼 때 효과 덧붙임 · 코스트 -1 · 개전).
- 화면: 강화 칩 · 쪽지 `powerOn` · `b.PowersOf()` — [API.md](API.md) 「강화 카드 지속 규칙」.

## 18. 보스 클론의 고학년(2026-10-06) — 데이터에 쓰지 않는다

**클론 전용 사도(`cloneHeroes`, 2026-10-11 엘다인 20명 전환)** — 플레이어 목록(`GameData.Heroes`)에서 뺀 사도도 보스 클론으로는 선다. 묶음 키 `cloneHeroes` 에 사도 꼴 그대로(`id` · `name` · `race` · `nature` · `star` · `ult` 가 쓰이고, 고학년 글에 필요한 `keyword` · `forms` 이름만 덧붙인다 — 카드 · `starter` · `passives` 는 없다)를 적으면 `GameData.CloneHeroes` 로 읽힌다. 클론 후보(`Run.CloneCandidates`) · 보스 고학년(`BossUlt`) · 빌린 몸(`MakeClone`) · 클론 성격(`Battle.FoeNature`)은 `GameData.CloneHero(id)`(플레이어 사도 먼저)로 찾는다. 같은 id 가 `heroes` 에도 있으면 검사 오류 — 사도를 되살리면 `cloneHeroes` 줄을 지운다. 콘텐츠: `world/clones/<종족>.json`.

1층 · 2층 보스 사도 클론(`boss: true` + `clone`)은 **그 사도의 고학년을 보스 특수 공격으로 쓴다.** 적 데이터에 따로 적을 것은 없다 — 엔진(`Runtime/Combat/BossUlt.cs`)이 사도 JSON 의 `ult` 를 싸움마다 적 쪽으로 바꾼다(사도 고학년을 고치면 보스도 따라 바뀐다).

- **예고는 고학년만**(사용자 2026-10-07) — 보스 몸의 평소 수는 무작위(shuffle)이고 힘 모으기가 없다(옛 몸의 모아 쏟던 수는 바로 하는 수로, 값 × 0.65 — 생성기 `_gen/foes/build.py` `BOSS_UNCHARGE`). 엘리트 · 일반의 힘 모으기는 그대로 있다(§적 리워크 문서).
- **때** — 2턴째에 **예고**(수 `charge` — 이름 = 고학년 이름, 머리 위에 다음 턴 피해 `b.UltHit`) → 3턴째에 **사용**(수 `ult`). 그 뒤 4턴마다(6 → 7, 10 → 11 …). 한 싸움에 클론이 둘이면 둘째는 한 턴씩 늦게. 예고 · 사용 턴은 평소 수의 차례를 건너뛰지 않는다(쉬었다 이어 간다). 즉시 행동으로 당겨지지 않는다.
- **끊기** — 예고 턴이나 사용 턴에 **격파**하면 끊긴다(카제나의 강한 의도 끊기 — `brk` 와 같다). 기절로 쉬게 해도 끊긴다. **끊으면 그 보스에 취약 2**(`BossUlt.CUT_VULN` — 모은 힘이 되튀어 무방비, 2026-10-07). 끊긴 뒤에도 다음 예고는 4턴 뒤.
- **바꾸는 법**(`BossUlt.Plan`)
  - 적에게 피해(`dmg`) → **파티에게 피해 한 번.** 값 = 층 기준(**1층 300 · 2층 360** — 2026-10-07 210 · 250 에서 올림 · 원값, 전투의 층 피해 배율이 따로 곱해진다) × √(고학년 피해 비율 합 ÷ 1.8)(0.8~1.25). 대상이 적 전체면 전체 공격(값 ÷ 2), 여러 대면 연타(최대 5대), 아니면 공격. 피해가 없는 고학년은 기준의 **85%**(옛 60%) 전체 공격을 붙인다.
  - 적 디버프 → **파티 디버프**(원작 값 **+ 1**(`DEBUFF_PLUS`) — 약화 · 취약 · 충격 · 손상 3, 고통 · 균열 4, 미끄러움 2까지 · 잔불 · 그을림 → 고통 3까지). 둔화 · 기절 → **파티 다음 턴 AP -1**.

### 19-1. 공용 계기(`when.on`)

```json
{ "name": "되갚기", "when": { "on": "guardSum" }, "fx": [ { "k": "dmg", "ratio": 1, "ofEvent": 0.5, "target": "oneEnemy" } ] }

```

**같은 갈래는 한 사도만(인원 세기 시너지 없음).** 한 번의 일에 `who: any` · `other` 로 반응하는 규칙(+ `keepAp`)은 **같은 `style` 의 사도 가운데 먼저 선 한 사도만** 돈다(그 사도의 다른 규칙은 다 돈다). 갈래가 다르면 따로 돈다. 장비 · 강화(power) 규칙 · `style` 이 없는 사도는 상관없다.

### 19-2. 효과 조각 · 칸

| 조각 | 쓰는 법 | 뜻 |
|---|---|---|
| `empower` | `{ "k": "empower", "ratio": 0.5 }` · `"who": "any"` | 다음 카드의 피해 · 실드 · 회복 +ratio. 기본 = 이 사도의 다음 카드, `any` = 파티의 다음 카드(상태 · 저주 카드는 안 쓴다). 여러 번 걸면 더해져 한 장에 다 쓴다 |
| `make` + `owner` | `{ "k": "make", "id": "빵", "owner": "other" }` | 만든 카드의 **주인**: `self`(기본) · `other`(파티 차례로 만든 사도 다음 아군) · 사도 id. 손패는 파티에 하나라 「다른 아군 손에 만들기」 는 없다 — 주인을 바꾼다(그 사도의 카드로 나가고 그 사도 능력치로 친다). 엔진 id 는 「카드@사도~」 |
| `spend` + `pick` | `{ "k": "spend", "id": "꿀", "pick": true }, { "k": "perEvent" }, { "k": "dmg", "ratio": 0.6 }` | 낼 때 **소모량을 고른다** — 화면 · 봇은 `b.SpendChoices(카드)`(1 · 절반 · 전부)에서 골라 `PlayOpts.Spend` 로(안 주면 전부). 소모한 양이 일의 값(`perEvent`). 자기 주머니(carrier self) 고유 효과만 |
| `perGuarded` | `{ "k": "perGuarded", "per": 20 }` + 피해 · 실드 · 회복 | 막아 낸 양 per 당(적의 차례 중이면 이번 판 몫, 내 턴이면 지난 판 + 이번 판) |
| `perOverheal` | `{ "k": "perOverheal", "pct": 0.8, "per": 25 }` + … | 이번 판 회복의 넘친 몫 합 per 당(`pct` 있으면 그 선을 넘은 몫) |

### 19-3. 다 차면 — `keyword.onMax`

저절로 터지는 대신 고르는 맛을 남기는 셋(하나만):

```json
"onMax": { "make": "시그니처카드id", "n": 1, "consume": true }
"onMax": { "empower": "next", "ratio": 0.5, "consume": true }
"onMax": { "form": "변신id" }
```

- `make` — 최대(cap)에 닿으면 그 카드 n 장(기본 1)을 손에(주인 = 그 사도, 손이 가득이면 버린 더미). `consume` 이 없으면 겹이 최대에 머물러 다시 만들지 않는다(검사기 주의).
- `empower` — `next`(그 사도의 다음 카드) · `any`(파티의 다음 카드)에 +ratio.
- `form` — 옛 그대로(§16).
- 같은 일을 규칙으로 쓸 수도 있다: `{ "when": { "on": "stackReach", "id": "X", "n": 5 }, "fx": [ { "k": "spend", "id": "X", "all": true }, { "k": "make", "id": "…" } ] }`.

**검사기(1단계).** 갈래(`style`)가 있는 사도가 「다 차면 저절로 터짐」 을 쓰면 주의 — **쌓고 고르기도 센다**. 터짐 = `stackReach` · `stackOver` 규칙에 `make` · `empower` · `spend` · `cue` 말고 다른 효과가 있거나 `onMax` 가 `form`. 이 주의 수가 135명 손놀림 교체의 진행률이다.

|---|---|

| `who: any` 공용 계기가 같은 갈래 인원만큼 | 19-1 「같은 갈래는 한 사도만」 |

### 22-7. 엘다인 검사기(▶E29)

엘다인 사도(`Run.NO_CLONE` 20명 id)에만. `bz check` 의 **오류**:

1. **기본 카드** = 그 사도의 고유 · 생성이 아닌 카드 — 꼭 **3장**, 모두 시작 덱. 효과는 **조각 하나**(`dmg` · `shield` · `heal` — 칸은 `ratio` · `target` · `base`만), **태그 · 조건 · 신탁 · 축복 · 덧효과 없음**.

### 25-2. 봇 · 측정(▶E87 때 보고 쥐기 — E9 늘림)

### 25-3. 같은 기본 카드 2장(사용자 2026-10-11)

가벼운 덱 사도의 1코 기본 공격 2장은 **같은 카드 2장**(이름 · 그림 · id 같음 — 카제나처럼). `starter` 에 같은 id 를 두 번 쓴다: `"starter": ["시온더다크불릿_s1", "시온더다크불릿_s1", "시온더다크불릿_s3", "시온더다크불릿_u1"]`.
- 엔진은 덱 · 전투 · 빛(신탁 · 은총은 한 장에만 — `Battle.LightOne`) · 저장 · 복제(`^`) 를 같은 id 여러 장으로 이미 다룬다. 카드 빼기(상점 · 이벤트)는 같은 카드가 덱에 남아 있으면 그 카드의 신탁 · 축복 · 카드 값을 지우지 않게 고쳤다.
- 검사기(E29 4차): 기본 카드는 **서로 다른 2~3종 · 시작 덱에 기본 3장**. 가벼운 = 1코 공격 1종 × 2장 + 1코 방어 1종 · 무거운 = 1코 공격 · 2코 공격 · 1코 방어 각 1장(그 밖의 꼴 · 2코 실드는 오류). 같은 카드 2장은 가벼운 덱의 1코 기본 공격만. 옛 「같은 내용 두 장은 이름이 달라야」 는 없앴다.
- 화면(runui): 사도 상세 「시작 카드」 줄은 두 장을 다 그리고 부제에 「4장(기본 3 · 시동 1) · 자기 카드 8장(기본 3 + 고유 5)」. 편성의 글 줄은 「이름 ×2」. 시작 덱 창 · 덱 보기는 두 장을 그린다.

### 25-4. 카드 종류와 적 피해(사용자 2026-10-11)

엘다인 카드(기본형 · 신탁 · 생성 카드)마다 그 모습(신탁의 `type` · `power` 를 얹은 모습)으로 본다 — 종류가 「스킬」 인데 적 피해(`GameData.HitsFoe` — 적 대상 `dmg` · `extra`)가 있으면 **오류**, 「공격」 인데 적 피해가 전혀 없어도 **오류**(사용자 2026-10-11 — 주의에서 올림 · 소환물 따라 치기 `summon` 은 적 피해로 센다). 적을 치는 카드는 공격 카드로(신탁이면 `"type": "공격"`).

### 25-5. 태세(사용자 2026-10-11 — 카제나 린 「흑운태세」 꼴)
