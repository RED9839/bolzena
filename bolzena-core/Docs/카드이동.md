# 카드 이동 · 드로우 (카제나 규칙)

2026-10-10 사용자 결정: **카드 이동 · 드로우 규칙을 카제나와 같게.** 근거는 카제나 커뮤니티 정리(사용자 제공) — 아래 「카제나」 칸.

## 더미

| 더미 | 엔진 | 비고 |
|---|---|---|
| 뽑을 더미 | `Battle.Draw` (끝 = 맨 위) | |
| 손패 | `Battle.Hand` | 최대 `R.HAND_MAX` |
| 버린 더미 | `Battle.Discard` | 카제나 원작 이름 「무덤」 = 버린 더미 **전부**(이번 턴에 낸 카드 포함) |
| 이번 턴에 낸 카드 | `Battle.Used` | 카제나 「이번 턴에 사용한 카드」 공간. 카드는 버린 더미 **안에** 있고 `Used` 는 그 표시(같은 이름은 버린 더미 뒤쪽부터 짝짓는다) — 화면 · 저장 모양은 그대로. 낸 카드가 버린 더미로 갈 때(바뀐 카드 포함) 붙고, **턴 끝**(손패를 버릴 때)에 비운다 |
| 소멸 더미 | `Battle.Gone` | |

「버린 카드」 = 버린 더미 − 이번 턴에 낸 카드.

## 규칙

| # | 카제나 | 엔진 | 데이터 · 카드 글 |
|---|---|---|---|
| 1 | 손으로 들어오는 길은 셋 — 생성 · 드로우 · 핸드로 이동. **생성은 드로우가 아니다** | `make` → 감응 · 영감 · 「카드가 뽑히면」(`drawn`) 없음. 은총 카드 · 적이 끼워 넣는 카드도 생성 | `make` — 「… N장 생성」 |
| 2 | **드로우 = 뽑을 더미 → 손.** 핸드로 이동이라도 뽑을 더미에서 오면 드로우, 버린 더미에서 오면 아님 | `DrawCards` · `pull from:draw`(손으로) 는 드로우(`Drawn` +1 · `AfterDraw`). `pull from:discard/discarded/gone` 은 드로우 아님 | `draw` — 「드로우 N」 · 「자신의 공격 카드 1장 드로우」. `pull from:draw` — 「뽑을 더미 맨 위 … 1장 드로우(없으면 섞지 않음)」 |
| 3 | 감응(드로우했을 때)은 **드로우일 때만** — 턴 시작 · 효과 드로우 · 뽑을 더미에서 손으로 포함, 생성 · 버린 더미에서 이동은 미발동 | `when on:"drawAny"`(감응) · 패시브 `drawn` 은 모든 드로우에. `when on:"draw"`(영감) 은 효과 드로우에만(상태 · 저주는 턴 시작도) — 둘 다 `AfterDraw` 한 곳에서 | TIPS 감응 · 영감 갱신 |
| 4 | 드로우할 때 (조건에 맞는) 카드가 뽑을 더미에 없으면 버린 더미를 뽑을 더미로 되돌리고 처리. **이번 턴에 사용한 카드는 그 턴 섞기로 돌아가지 않는다**(무한 루프 방지) | `Reshuffle()` — 버린 카드만 뽑을 더미로(남은 뽑을 더미와 함께 섞음), `Used` 는 버린 더미에 남는다. 버린 카드가 없거나, 섞은 뒤 「섞으면」 계기(우로스 「순환」 드로우 등)가 섞인 카드를 먼저 가져가 뽑을 더미가 비면 드로우 멈춤(뽑을 게 없으면 못 뽑는다). 조건 드로우(`draw` + 거르개)도 맞는 카드가 없으면 섞고 한 번 더 찾는다(전엔 섞지 않고 그만). 적의 「빼앗기」(`seize`) 섞기도 같은 규칙 | |
| 5 | 「**버린 더미에서** 손으로 이동」 은 이번 턴 사용한 카드도 가져온다. 「**버린 카드에서**」(압류) 는 못 가져온다 | `pull from:"discard"`(기본) = 버린 더미 전부 · `pull from:"discarded"` = `Used` 뺀 버린 카드만. 이번 턴에 낸 카드를 꺼내면 `Used` 표시도 뗀다 | 「버린 더미 맨 위 카드 1장을 손으로」 · 「버린 더미(이번 턴에 낸 카드 빼고) 맨 위 카드 1장을 손으로」 |
| 6 | **선택 후 드로우**(호기심 · 공격하라!) — 대상이 뽑을 더미에 없으면 **셔플 없이 불발**(카드는 사용됨) | `pull from:"draw"` — 뽑을 더미에서 고른 뒤 꺼내므로 없으면 섞지 않고 그만(카드는 낸 것으로) | 「…드로우(없으면 섞지 않음)」 |

### 드로우가 아닌 것(손으로 들어와도)
생성(`make` · 은총 · 적 `addCard`) · 버린 더미 / 소멸 더미에서 꺼내기(`pull from:discard · discarded · gone`) · 회수(낸 카드가 손으로) · 빼앗긴 카드 되찾기 · 개막(덱에서 바로 「사용」 — 손을 거칠 뿐 드로우 아님).

### 하지 않은 것
- 6의 둘째 경우(범위에 버린 카드가 더해진 선택 드로우 — 뽑을 더미에서 고르면 드로우, 버린 카드에서 고르면 아님): 쓰는 데이터가 없어 출처를 섞는 `from` 은 만들지 않았다. 필요하면 `from:"draw"` 와 `from:"discarded"` 를 차례로 두 번 쓰면 같은 뜻.
- 적의 「다시 섞기」(`reshuffle` 행동 — 손패를 버리고 뽑을 · 버린 더미를 모두 섞음)는 적의 차례라 `Used` 가 이미 비어 있다. 그대로 두고 `Used` 만 비운다.

## 기존 데이터 매핑
- `pull` 36곳(슈로 · 티그 · 네티 · 레테 · 바롱 · 에스피 · 라이카 · 블랑셰 · 잉클 · 교주 카드 n_rearguard) 은 모두 `from:"discard"` — 글이 「버린 더미 … 손으로」(버린 더미 전부)라 **그대로**. 데이터 고침 없음. 「버린 카드에서」 뜻으로 바꾸고 싶은 카드는 `from:"discarded"` 만 바꾸면 글이 따라간다.
- `pull from:"gone"` 12곳 · `make` · `draw` 는 그대로.
- 감응(`drawAny`) · 패시브 `drawn` 을 쓰는 사도 데이터는 지금 없다(엔진 · 테스트만).
