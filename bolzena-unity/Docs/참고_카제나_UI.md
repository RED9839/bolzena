# 참고 — 카제나 화면(UI) 구성 · 아이콘

2026-10-21 · **조사 문서**(코드 · 콘텐츠는 고치지 않음). 볼제나 화면을 다듬을 때 비교용.
대상: 「카오스 제로 나이트메어」(카제나, 스마일게이트 · 슈퍼크리에이티브, 2025-10-22 출시).
이 문서의 외부 게임 이름 · 용어는 **참고 설명용**이다. 게임 화면 글에는 쓰지 않는다.

**출처와 그 한계**
- 화면 배치를 글로 적은 출처가 거의 없어 공략 글 · 기사의 스크린샷 약 120장을 직접 보고 적었다(GameWith · GameUI Lab · TierTactix · Prydwen · sforum · playday.one · 게임와이 · 플레이포럼 · 게임플 등). 대부분 **출시 직후(2025-10~11) 화면**이라 그 뒤 패치로 바뀌었을 수 있다.
- 표기: 「(그림)」 = 그림만 보고 읽은 것, 「추측」 = 짐작, 「**확인 필요**」 = 출처끼리 다르거나 한 곳에서만 나왔거나 못 찾은 것.
- arca.live · Prydwen 일부 · 일본 위키는 403, 나무위키 「…/시스템」 은 404, STOVE 공지는 빈 페이지로 와 못 읽었다. 접근일은 모두 2026-10-21.
- 스크린샷 원본: 스크래치패드 czn_img(전투 · 보상) · czn_chr_img(전투원) — 임시 폴더라 남길 것은 따로 옮겨야 한다.
- 관련 문서: [참고_카제나_성장.md](참고_카제나_성장.md) · [참고_카제나_잠재력.md](참고_카제나_잠재력.md)(규칙 · 수치는 그쪽).

## 메인 로비

**출처와 그 한계(로비)**
- 로비 배치를 글로 설명한 출처는 거의 없다. 그래서 **공략 글에 실린 게임 캡처를 직접 내려받아 눈으로 읽었다**(GameWith 영문판 캡처 · GameUI Lab 일본어판 캡처 · 게임와이 · 플레이포럼 · 블로그 asecurity.dev 한국어판 캡처). 캡처 시점은 대부분 출시 직후(2025-10~11)라 지금 화면과 다를 수 있다.
- 한국어 메뉴 이름 중 일부는 영문 · 일본어 캡처만 있어 **번역 대응으로 짐작**했다(표에 표시).
- 나무위키 「평가」, 루리웹 「개선해야 하는 부분 100가지」, 인벤 시즌4 기사로 기능 변화와 유저 평가를 보탰다.
- 기존 로컬 수집(카제나_시스템_수집.md, 2026-10-08)에는 로비 서술이 없다. 방주도시 시설 목록 · 가챠 줄만 겹친다(13절, 출처 나무위키 5.3).
- 나무위키 「시스템」 하위 문서는 없었다(404). arca.live · Prydwen · 일본 위키(aosns)는 403 이라 검색 요약만 봤다.
- 「**확인 필요**」 = 출처끼리 다르거나 한 곳에서만 나온 것, 또는 못 찾은 것. 접근일은 모두 2026-10-21 이다.

### 0. 한눈에

| 영역 | 무엇이 있나 | 근거 |
|---|---|---|
| 배경(가운데) | 함선 「나이트메어호」 함교. 창밖으로 지구 · 은하가 보이고, 앞줄 콘솔 좌석에 승무원(전투원)이 앉아 있다. 그 앞에 **전투원 1명 전신 일러스트**가 선다 | 캡처(GameWith · GameUI Lab), GameUI Lab 글 |
| 왼쪽 위 | 함장 **Lv.** 큰 숫자 + 이름 + 경험치 % 막대(주황) → 누르면 ID 카드 | 캡처, GameWith ID 카드 글 |
| 그 아래 | 진행 중 과제 한 줄(아이콘 + 「[성장] 3회 완료 0/3」 식). 성장 가이드 바로가기로 보인다 | 캡처 |
| 오른쪽 위 | 에테르 `240/240 +` → 아이콘 3개 → 햄버거(☰) | 캡처 |
| 오른쪽 | **세로 메뉴 6개**(글자 + 흰 선 아이콘, 오른쪽 끝에 세로 점선 축) | 캡처 |
| 왼쪽 아래 | 「창」 모양 아이콘(로비 꾸미기) + 그 밑 작은 배너 슬라이드(페이지 점 □□■) | 캡처, 블로그 |
| 오른쪽 아래 | 큰 기간 배너(예: 「은하계 재해」 + 남은 시간 「57일 5시간」) | 캡처(일본어판) |
| 맨 아래 왼쪽 | `UID:…` 작은 글자 | 캡처(영문판) |
| 아래 바 | **없다.** 하단 탭 바 구조가 아니다 | 캡처 전부 |

**가장 큰 특징 셋**
1. **오른쪽 세로 목록 하나에 주 콘텐츠를 다 모았다.** 하단 바 · 좌우 양쪽 메뉴가 없고, 나머지는 오른쪽 위 작은 아이콘과 ☰ 로 뺐다.
2. **로비 상단 재화는 에테르 하나뿐이다.** 크리스탈 등은 상점 · 충전 창처럼 쓰는 화면에서만 뜬다(화면마다 그 화면 재화만 보임).
3. **흰 바탕 · 얇은 선 · 주황 강조의 「깨끗한 SF」 틀** 위에 어두운 우주 배경과 캐릭터 일러스트를 얹는다. 알림은 **빨간 마름모**로 통일.

### 1. 로비 화면 배치(자세히)

#### 1-1. 왼쪽 위 — 함장 정보

| 요소 | 모양 | 동작 |
|---|---|---|
| 레벨 | 「Lv.」 작은 글자 위, 큰 두 자리 숫자(07). 어두운 반투명 사다리꼴 판 | 누르면 계정 정보 → ID 카드 |
| 이름 | 숫자 오른쪽 흰 글자 | — |
| 경험치 | 「11%」 + 가는 막대, 찬 부분 **주황** | — |
| 진행 과제 | 원형 기호 아이콘 + 「○○ 3회 완료」 + 「0/3」 | 성장 가이드 과제로 보임 — **확인 필요**(캡처만) |

- ID 카드 화면(계정 정보): 왼쪽 탭 **ID 카드 · 친구 목록 · 친구 찾기 · 받은 초대 · 차단 목록**(영문 캡처: ID Card · Friend List · Find Friend · Received Invites · Block List). 본문에 UID, 배너 일러스트, Lv · 경험치, 함장 등급(「No Captain Rank」), 자기소개, **대표 전투원 6칸**. 한국어 탭 이름은 **확인 필요**.
- 함장 등급 5단계: 초급 · 중급 · 베테랑 · 전문 · 엘리트(영문 Beginner~Elite, 전투원 레벨 상한 20~60). 진급 임무로 오른다. 한국어 이름은 **확인 필요**.

#### 1-2. 오른쪽 위 — 재화 · 아이콘 줄

| 순서 | 모양 | 뜻 |
|---|---|---|
| 1 | 은빛 캡슐(보라 빛 액체가 든 약병, 비스듬) + `240/240` + `+` | **에테르**(스태미나). `+` 를 누르면 「에테르 충전」 창 |
| 2 | 달력에 별 | **추측**: 이벤트. 초반엔 자물쇠 |
| 3 | 줄무늬 카드/서류 모양 | **추측**: 패스(시즌 보급) 또는 공지. 초반엔 자물쇠 |
| 4 | 둥근 네모 안 원형 기호(왼쪽 진행 과제 아이콘과 같은 기호) | **추측**: 임무 창(당일 일정 · 성장 가이드 · 업적) |
| 5 | ☰ 햄버거 + 빨간 마름모 | 전체 메뉴. **안의 목록은 못 찾음 — 확인 필요**(쿠폰 글에 「설정 → 실루엣(계정) → 쿠폰 등록」 경로만 나옴) |

- 아이콘 사이는 얇은 세로선으로 나눈다. 아이콘은 흰 선 그림, 배경 없음.
- 2~4번이 각각 무엇인지는 이름표가 없는 캡처뿐이라 **확인 필요**.

#### 1-3. 오른쪽 — 주 메뉴(세로 6개)

| 순서 | 한국어 이름 | 영문 / 일본어 캡처 | 아이콘 모양 | 아래 작은 글 |
|---|---|---|---|---|
| 1 | **임무** | Missions / 任務 | 다른 것보다 **큰 원형 그림 버튼**(행성 · 문양, **주황 테두리 고리**와 빛 번짐) | 「1장 5화」처럼 현재 진행 |
| 2 | 시뮬레이션 | Simulation / シミュレーション | 원자(궤도 3개) | 가짜 문자 + 작은 네모 |
| 3 | 카오스 | Chaos / カオス | 원 안 육각 격자(측지선 구) | 〃 |
| 4 | 방주도시 | Ark City / 箱舟都市 | 높은 빌딩 3동 | 〃 |
| 5 | 전투원 | Combatants / 戦闘員 | 사람 셋(가운데 하나 큼) | 〃 |
| 6 | 구출 | Rescue / 救出 | 겹친 동심원(렌즈 · 표적) | 〃 |

- 잠긴 메뉴는 글자 앞 **자물쇠** + 회색. 누르면 가운데 흰 띠 창 「콘텐츠 잠김 + 해금 조건(▷ 바로가기)」, 아래 「화면을 터치하면 창이 닫힙니다」.
- 글자는 오른쪽 정렬 흰 글, 아이콘은 오른쪽, 그 오른쪽에 세로 점선 축과 작은 빛 점(선택 표시).
- 각 이름 밑 「읽을 수 없는 가짜 문자」는 장식이다(GameUI Lab).
- 한국어 이름: 방주도시 · 카오스 · 시뮬레이션은 한국어 캡처 · 기사로 확인. **임무 · 전투원 · 구출**은 기사 · 나무위키 용어(「전투 임무」 「구출 뽑기」 「전투원」)로 맞춘 것이라 로비 표기 그대로인지 **확인 필요**.
- 상점 진입 단추는 로비 캡처에 안 보인다. ☰ 안에 있을 것으로 **추측**.

### 2. 로비에서 들어가는 화면 · 메뉴 깊이

```
로비
├─ [왼쪽 위 Lv] → 계정 정보(ID 카드 · 친구 · 찾기 · 초대 · 차단)
├─ [에테르 +] → 에테르 충전 창(신의 눈물 · 에테르 빈 파우더 · 크리스탈 3택)
├─ [오른쪽 위 아이콘] → 임무 창(왼쪽 세로 탭 3개: 당일 일정 · 성장 가이드 · 업적 기록*)
├─ [☰] → 전체 메뉴(상점 · 우편함 · 설정 등으로 추측)
├─ 임무 → 스토리 | 전투 임무(큰 그림 카드 2장) → 장 선택 → 화
├─ 시뮬레이션 → 상단 탭 [전투 훈련 | 초공간의 유역] → 세로 캡슐 카드 6개(성장 · 전투원 · 파트너 · 잠재력 · 기억의 조각 · 도전) → 팀 편성 → 진입
├─ 카오스 → 카오스 발현(원형 노드 지도: 푸른 항아리 · 미확인 카오스…) → 팀 편성
├─ 방주도시 → 지도(중심가 · 아카데미 · 휴양지 · 행정 구역 + 아래 시설 바: 정책실 · 별빛 식당 · 정원 카페 · 에피오네 센터 · 연구 시설 · 노노 상점)
├─ 전투원 → 전투원 목록 → 상세(능력치 · 카드 · 파트너 · 세이브 데이터 · 잠재력 · 에고 발현)
└─ 구출 → 뽑기
```
\* 「업적 기록」 은 영문 「Achievement Log」 를 옮긴 것, 한국어 표기 **확인 필요**.

- 깊이는 대체로 **로비 → 콘텐츠 허브 → 세부 → 편성 → 진입**의 3~4단이다.
- 임무 창 · 우편함 · 에테르 충전은 **새 화면이 아니라 로비 위 팝업**이다(배경이 흐려지고 오른쪽 위 ✕). 임무 창은 왼쪽에 서류철 탭이 튀어나온 모양.

#### 2-1. 공통 화면 틀(하위 화면)

| 위치 | 요소 | 모양 |
|---|---|---|
| 왼쪽 위 | 뒤로 | **흰(또는 검은) 둥근 네모 안 ◁** + 바로 옆 화면 제목(「방주도시」 「팀 편성」 「상점」) |
| 오른쪽 위 | 그 화면 재화 | 어두운 알약 모양 칸에 아이콘 + 숫자(카오스: 전리품 인증서 3/4, 정원 카페: 파우더 0/4 + 에테르, 상점: 교환 재화, 별빛 식당: 유닛) |
| 오른쪽 위 끝 | **홈(집 모양) │ ☰** | 집 아이콘과 햄버거 사이 얇은 세로선, ☰ 에 빨간 마름모 |
| 왼쪽 | 하위 탭 | 세로 목록, 선택 항목은 **검은 알약 + 흰 글**, 앞에 작은 점 · 고리 표시 |
| 아래 | 주 행동 단추 | **주황 넓은 단추**(진급 · 확인 · 모두 받기) |

- 상단 재화는 로비처럼 고정되지 않는다. **화면마다 그 화면에서 쓰는 재화만 보인다.**

#### 2-2. 빨간 점 알림

- 모양: **빨간 마름모(45° 돌린 네모) + 흰 테두리**, 아이콘 · 카드의 오른쪽 위 모서리에 붙는다. ☰ · 메뉴 · 전투원 카드 · 임무 탭 모두 같은 표시다.
- 새 항목엔 주황 원 안 「N」 배지도 쓴다(스토리 카드, 난이도 4).
- 시즌4부터 심리 상담에서 아직 안 고른 선택지에도 레드닷을 단다(인벤).

## 전투원 화면 — 조사 범위와 한계
