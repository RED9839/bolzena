**한눈에**
- 적 = 등급(S 보스 · A 엘리트 · B~D 일반) + 세력 + 약점 1개 + 고유 패시브 1~2개. 패시브가 곧 기믹이다.
- 강인도: 약점 카드 비용 1당 1칸(0비용 0.5) · 약점 아님 1/3 · 광역 1/2. 격파 = AP 1 · 스트레스 감소 · 행동 카운트 +1, 다음 턴 회복.
- 행동 카운트 = 행동까지 남은 카드 사용 수(0 이면 내 턴 중이라도 행동, ∞ 면 턴 끝).
- 약점은 상성 표 없이 「같은 속성이면 보너스」. 세력마다 약점이 정해져 카오스(행성) 고르기 = 파티 속성 고르기.
- 보스는 대부분 2페이즈 · 딜 레이스. 페이즈가 HP 보다 피격 수 · 카드 수 · 코스트 스택으로 바뀌는 경우가 많다. 격파는 보스 기믹을 푸는 열쇠로 쓰인다.
- 고난도 점수전(대균열)은 준 피해 기준이지만 일정량 넘으면 수확 체감 · 카드 한 장 점수 상한 · 방어 몫 점수가 있다.

# 1. 적 체계 · 일반 · 엘리트

## 적 체계

> 범례: 「확인」 = 둘 이상 출처가 같거나 사전 · 공식에 가까운 출처, 「(한 곳)」 = 한 출처만, 「**확인 필요**」 = 출처끼리 다르거나 못 찾음, 「추측」 = 내 해석. 출처 번호는 맨 끝 「출처(체계)」 표.

### 1. 적 한 마리가 가진 것

| 요소 | 내용 | 근거 |
|---|---|---|
| HP | 분홍 막대 + 숫자. 수치는 난이도 · 등급마다 다르다. **몬스터별 HP 표는 어떤 출처에도 없다**(나무위키 도감도 HP 칸 없음) | [1][13] · **확인 필요** |
| 공격 · 방어 | 적 방어력 수치는 화면 · 출처에 안 나온다. 방어 쪽은 **실드(파란 방패 + 숫자)** 와 **불굴 · 피해 감소 · 고유 패시브**로 표현된다 | [13] · 방어력 수치 **확인 필요** |
| 등급 | 보스 **S** · 엘리트 **A** · 일반 **B~D**(C · D 는 약한 졸개). 등급이 오를수록 패시브가 1 → 2개 | 확인 [1][14] |
| 세력 | 변이체 · 카오스 교단 · 인베이더 · 니힐럼 · 세크레드 · 디알로스 · 악칼리온 · 성전십자회 · 다크스타 | 확인 [1] |
| 약점 속성 | 한 마리에 **1개**. 행동 카운트 옆 작은 육각 배지(색 = 속성). 적 정보 창에서도 본다 | 확인 [1][3][13] |
| 고유 패시브 | 「이름 + 한 줄 규칙」 1~2개. 이것이 곧 기믹(예: 야생의 감 · 기생체 · 무리 비행) | 확인 [1][14] |
| 강인도 | 일부(강한) 몬스터만. HP 막대 밑 칸 나뉜 막대 | 확인 [2][3][4] |
| 행동 카운트 · 행동 예고 | 아래 3 · 4 절 | |
| 데스신 | 보스 · 엘리트(와 일부 B급)가 파티 전멸 때 쓰는 전용 처형 연출. 나이트메어 모드에서 나온다 | 확인 [1][15] |

### 2. 강인도 · 격파

| 항목 | 내용 | 근거 |
|---|---|---|
| 깎는 양(약점 · 단일) | 공격 카드 **비용 1당 1칸**, 0비용 0.5칸 (0=0.5 · 1=1 · 2=2 · 3=3) | 확인 [5][16] |
| 약점이 아닐 때 | **1/3** | 확인 [5][16] |
| 광역 · 대상 없음 공격 | **1/2** | 확인 [5][16] |
| 천상 · 표식 · 협공 | 약점이어도 **0.5칸** 고정 | (한 곳) [16] |
| 에고 스킬 | 약점 단일 **EP 1당 0.5칸**, 비약점 0.166칸, 광역 1/2 | (한 곳) [16] |
| 직접 강인도 피해 | 카드 · 장비의 「강인도 피해 N」(신성한 일격 2, 나르쟈 모든 적 2, 잔광 = 공격 카드 강인도 피해 +1) | 확인 [6][13] |
| 격파(Ravage) 보상 | **AP 1 획득**, **격파한 전투원 스트레스 감소**(나무위키 「1 줄어든다」), **그 적 행동 카운트 +1** | 확인 [2][3][4][5][6] |
| 격파 상태(Broken) | 「강인도가 완전히 붕괴된 상태」. **기본으로 받는 피해가 늘어나는지는 어떤 출처에도 없다**. 「격파 상태인 대상에게 +x%」는 카드 · 장비 · 파트너가 주는 것(프리실라 +25~50%, 잔광 +50%, 무기 +30%) | [6][7] · 기본 증가 **확인 필요** |
| 기절? | oslink 만 「격파 상태 = 기절(stunned)」로 적었다. GameWith · Prydwen 은 「행동 카운트 +1(지연)」 | **확인 필요**(다른 출처는 행동 취소가 아니라 1칸 지연) |
| 회복 | 깎인 강인도는 **다음 턴에 회복** → 매 턴 다시 노릴 수 있다 | (한 곳) [2] |
| 격파 = 처치와 겹칠 때 | 마지막 일격으로 격파 + 처치해도 AP 는 돌려받는다 | (한 곳) [4] |
| 몬스터별 고유 격파 효과 | 날개 인면수: 격파 시 사기 5 감소 | [1] |
| 운영 상식 | 스트레스가 높은 전투원으로 마무리 격파(스트레스 감소 몫), 강공격 직전에 격파해 행동을 미룬다, 고비용 카드는 격파용 · 광역은 격파에 약함 | [2][4][8] |

### 3. 행동 카운트(분홍 마름모)

| 항목 | 내용 | 근거 |
|---|---|---|
| 뜻 | 「몬스터가 행동할 때까지 남은 **카드 사용 횟수**」. 카드 1장 쓸 때마다 1 감소, **0이면 내 턴 중이라도 즉시 행동**, 행동한 뒤엔 다음 턴까지 기다린다 | 확인 [3][4][6][8] |
| ∞ | 카운트로 움직이지 않고 **내 턴이 끝난 뒤** 행동 | 확인 [3][4] |
| 시작값 | 몬스터마다 다르다(화면 예 11 · 10 · 2). 표로 정리한 출처 없음 | [13] · **확인 필요** |
| 늘리기(아군) | 격파 +1 · 「행동 카운트 증가」 카드 · 장비(피 묻은 펜던트: 복제 카드 사용 시 모든 적 +3) | 확인 [2][14] |
| 안 줄이기(아군) | **신속** 카드 = 적 행동 카운트를 줄이지 않음 | 확인 [6] |
| 줄이기(적) | **급속**(중첩당 카운트 1 더 감소, 소울 콜렉터 구울), **속박** 저주(컬티스트 아비터: 손에 있으면 카드 1장에 2씩 감소), 세넥투스(같은 전투원 카드 연속 → 즉시 0) | 확인 [1] |
| 카운트에 걸린 기믹 | 로튼 리퍼 「기생체 12」가 카운트와 함께 줄어 0이면 기생체 폭발, 휴먼 섀도 「카운트 3 안에 일정 피해 못 넣으면 동료에 사기 5」, 그을림(카운트 감소마다 ×80 지속 피해) | [1][6] |
| 에고 스킬은 세나? | itemlevel: 에고 스킬은 카운트를 **안** 줄인다 / oslink(일): 에고 스킬도 「카드 1장 사용」으로 **줄인다**. 붕괴 카드는 줄인다(itemlevel) | **확인 필요**(출처끼리 반대) |
| 한 턴 여러 번 | 크루얼 본(체력 절반 이하 추가 행동 1→2), 안개 속의 여인(행동 후 추가 행동 반복), 소울 콜렉터(턴 첫 행동에 강공격 추가) | [1] |
| 게임 뿌리 | 크로노 아크식 「행동력 카운트」 구조라고 나무위키가 서술 | [15] |

## 보스별 분석

> 수치는 출처에 있는 것만 적었다. HP 실수치는 카오스 난이도 · 시즌 배율에 따라 달라지고, 공개 자료에는 거의 없다(승급 미션 베르큘라 1,796만 확인). 「강인도」는 HP 아래 칸(Tenacity)이고, 다 깎으면 「격파」(Ravage)가 된다. 격파하면 적의 행동 카운트가 +1 늦춰지고, 아군은 AP 1을 얻으며 격파한 전투원의 스트레스가 줄어든다. 강인도는 다음 턴에 회복된다(GameWith). 보스마다 강인도 칸 수는 공개 자료에 없다.

| 페이즈 수 | 대부분 **2단계**(HP 40~65% 문턱 하나 또는 「한 번 죽이면 변신」). 역신만 가면 3단계 + 무적, 콜로서스는 부위 순환이다. HP 문턱은 40 · 50 · 65% 가 확인된다 |
| 페이즈 계기 | HP 문턱보다 **스택 계기**가 많다. 「피격 N회 → 상태 전환」(역신 · 단꿈 · 아네스 · 억압된 사용인 · 콜로서스), 「아군이 카드를 낸 수 → 스택」(쥬다스 · 아바르크), 「코스트 → 철갑」(신수) |

| 정보 전달 | 공식이 「설명 부족」 지적(역신)을 받아 1주년에 **행동 예고 팝업**을 넣는다 |

M.E.O.W(프리시즌.json): HP 600k · 강인도 10 · 「출력」(맞을수록 강해진다) · 「심심함」(안 때리면 대난동) · 통제 신호 끼워 넣기 · 드론 소환 · 충전(격파로 끊긴다) · 프레스 예고(실드로 받는다) · 잃은 HP 0.9375 / 0.75 에서 단계가 바뀐다. 최강 덱 시험 결과 「처치되어 상한에 몰린다 → HP ×4 · score_max 600k 제안」.
