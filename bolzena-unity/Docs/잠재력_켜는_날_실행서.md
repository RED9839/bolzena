- 표 `seasons` · 열 `score_max` · 줄 `id = 'preseason'`(유일한 시즌). `seasons.hp` 는 배율(1)이라 건드리지 않는다 — 보스 HP 는 콘텐츠(600,000).

## (e) 서버 PROG=1

`wrangler.toml` 에 `pages_build_output_dir` 가 있어 **설정 파일이 Pages 설정의 주인**이다 — 대시보드에서 평문 변수를 더하면 다음 배포 때 무시된다. 그래서 **시크릿**으로 넣는다(값은 비밀이 아니지만 시크릿은 toml 과 상관없이 붙고, toml 을 바꾸면 로컬 시험 `run-local.mjs` 의 「성장 끔」 서버까지 켜진다).

```bash
cd /c/projects/bolzena-unity/Web
printf 1 | npx wrangler pages secret put PROG --project-name bolzena   # 값은 stdin 으로(이 줄은 돌려 보지 않았다 — 값을 묻는 창이 뜨면 1 입력)
npx wrangler pages secret list --project-name bolzena | grep -E "^\s+- " | sed -E 's/:.*$//'   # 이름만 — PROG 가 보여야 한다(값은 찍지 않는다)
```
- 대시보드로 하려면: dash.cloudflare.com → Workers & Pages → **bolzena** → Settings → **Variables and Secrets** → Production → Add → Type **Secret** · Name `PROG` · Value `1` → Save.
- 시크릿은 **다음 배포부터** 붙는다 — (f) 배포 전에 넣는다.
